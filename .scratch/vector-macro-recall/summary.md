# 自动召回实现与验收

2026-10-22。需求见 [spec.md](./spec.md)，使用说明见 [README.md](../../README.md)。

自动召回默认关闭，每个对话保存一套配置。绑定已有全局／对话命名视图，以视图条件筛选完整记录，再在对应组选区复用向量检索。多个视图合并候选、记录去重、统一 Top K；输出按相关程度和字符预算保留来源。面板提供状态、实际查询、范围、索引覆盖与宏文本。

真实 ST 在保存用户消息后等待 MESSAGE_SENT，再展开角色卡与预设。事件桥返回召回 Promise，固定最多等待 10 秒；同步的 `{{memoryRecall}}` 只读取当前快照。停止、切对话与立即新发时，生成拦截器终止尚未退出的旧生成；重生成、swipe、续写与同批群聊复用当前有效快照。查询不等待补建，不自动重试，不修改预设或调用 setExtensionPrompt。

验证使用隔离的 SillyTavern 1.18.0：真实页面、事件、Generate 和提示词构建，embedding 与模型响应受控模拟。已检查 Chat Completion 和 Text Completion 最终请求中的角色卡／预设双宏；取消、跳过、10 秒超时、失败清旧、同空间 A→B→A、迟到响应、停止立即新发、重复生成、群聊和内部 Agent。另以延迟真实记录查询固定本地准备阶段，验证尚未发出 embedding 时切对话也不会放行旧生成。

筛选验收覆盖作用域固定、删除不回退、多值精确匹配、零匹配、条件字段无需向量化、105 条匹配完整分页、视图原 limit 不限制候选、条件字段修改失效、改名跳过、同表多个视图组选区不串用及重叠候选去重。桌面与 390px 界面均已检查。

代码验证：全量 124 个测试文件、1372 项测试通过；后续生命周期修复的 5 个相关文件、98 项回归通过。类型检查、lint、格式检查、构建与 diff 检查通过。

真实验收补充一项宿主边界：ST 自动 token 预估可能与正常发送交错，宏参数不带调用作用域。实现优先保护正常提示词，避免漏召回；独立 dry run 空宏，并发 dry run 可能计入当前召回，均不额外请求 embedding。首版不为此增加提示词队列或额外超时机制。
