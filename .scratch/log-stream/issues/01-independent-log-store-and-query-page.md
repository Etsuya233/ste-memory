# 01 — 独立日志库与日志查询页（写入任务开始行）

**What to build:** 日志改存到独立于记忆数据的数据库，日志页变成单纯的查询页：按类型/级别/Key 过滤，进入自动查一次、点「查询」刷新，点单条原样看到 Pretty JSON 文本，可清空。触发一次填表任务后，日志页能查到该任务的 `fill-task` 开始行（楼层范围、每批大小、开始时间）；任务 Tab 的活动任务卡片与历史任务行都能跳到它。删除记忆空间不再删除日志；旧版结构化日志不再显示、旧查看能力（解码/摘要/折叠）不复存在。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 日志存放在独立数据库：行含 type、key、level、text、createdAt 与自增序号；无记忆空间字段；超过全局 1000 行上限时自动删除最旧行。
- [ ] 查询页有三项过滤：类型（填表任务/填表批/Agent 请求 + 全部）、级别（信息/警告/错误 + 全部）、Key 文本（子串、大小写不敏感）。
- [ ] 查询行为：Key 非空按 Key 查询，否则取最近 1000 行；类型/级别在结果上过滤；进入页面自动执行一次；「查询」按钮刷新；结果时间倒序展示级别、类型、Key、时间。
- [ ] 点击单条日志原样展开文本（`<pre>` 纯文本，同一时间只展开一条）；页面无任何业务结构解析、类型专属摘要或状态文案解码。
- [ ] 「清空日志」清空独立库。
- [ ] 填表任务提交（含初始化填表）写入 `fill-task` 开始行：楼层任务含 kind、range、batchSize、startedAt；初始化任务省略 range；写入失败只记警告，不阻断任务。
- [ ] 活动任务卡片新增「日志」入口，历史任务行「日志」入口保留；两者都按任务 runId 过滤并在查询页生效。
- [ ] 删除记忆空间不再删除日志；日志不进入云同步、备份与对话文件镜像；旧主库日志表原地不动（不读取、不迁移、不删除）。
- [ ] 旧结构化日志能力删除：运行路径上不再有旧日志仓库及其按类型/空间查询方法、结构化运行记录类型与详情解码组件。
- [ ] 测试通过：独立库仓库测试（假 IndexedDB：追加/最近/按 Key/清空/超限修剪/无级联）与查询页模型测试（过滤组合、查询维度、列表视图模型）；删空间级联断言与空间维护的日志保留断言已按新库调整。

**参考**：本目录 `../spec.md`；决策见 ADR 0015。
