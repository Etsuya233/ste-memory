## 本轮范围

已接入原生 `semantic_scores(table_key, groups_json, query_text)`、执行内查询向量与评分共享、5 分钟成功查询向量 LRU、新 SQL 宏编辑及旧 sources 兼容。共享评分服务和 SQLite 端口放在 `features/semantic-query`，供宏调用；按用户最新要求，本轮未挂载 Agent 工具，也未修改既有 Agent SQL 读写视图。

SQLite 虚拟表同步读取完整评分行。缺少输入时通过语句局部结构化状态中断，外层异步准备并重执行；只发布完整成功轮，累计 SQL 时间和总等待预算均不重置。动态源限制为每 SQL 16 源、4 文本、17 轮。

查询向量缓存以捕获的连接配置 revision、profile 与 trim 文本区分，凭据变更也隔离；请求使用同份捕获配置。批次统一拥有取消，单宏失败不取消同批其他宏。L2 只接收成功且仍有效的结果，不保存记录、评分或输出，不共享跨批次在途请求。

## 自动化与端到端

Astra 终审发现旧 TEMP 评分表物化误占 SQL 1 秒预算，已恢复旧路径“物化只计总时限、物化后启动 SQL 预算”的边界；内联路径继续累计各轮成本。可控时钟回归验证 1,200 ms 物化加短 SQL 成功、总时限和 SQL 时限各自生效、失败后会话仍可使用。

原生引擎使用真实 SQLite WASM 测试，多源、动态行参数、游标、空源 JOIN／COUNT／EXISTS、部分行丢弃、权限、预算和依赖分类均有回归。缓存测试覆盖 L1、L2、TTL、LRU、载荷上限、凭据修改、失败及取消；宏服务检查错误诊断和关闭失败不阻塞主生成。

真实 ST 使用专用角色、空间和记录，主生成响应受控模拟。合成向量脚本覆盖 Query／内联 SQL／旧 sources 共享、重生成 L2 与新快照、显式测试隔离、双游标与 UNION、旧格式转换失败保留、取消迟到、缓存重发、凭据 revision 和预设分类。运行前备份原构建五件文件，结束清理专用数据、恢复设置并逐一校验构建 SHA256。

本轮外部 embedding 验收统一预算最多 3 个已发 POST，由持久计数文件在发出前递增；索引、失败和取消请求都占次数。无自动重试、不跟随重定向；合成测试不读取真实密钥。最终真实轮仅验证一条索引、一次冷查询和一次新文本取消，其余复用已有成功输入，避免重复收费。

## 范围与限制

原生回调仍同步，网络和全源评分由外层完成。随机或逐行变化的参数可能用完动态源预算，已发请求可能计费；只返回最后成功一轮，无部分结果。普通 Query 和旧 sources 保持原预算，不套用动态发现上限。

当前 ST 的用户消息提前展开、并发 quiet 的操作归属、取消门禁加载顺序等边界保持，见 [上一轮记录](../macro-expression-refactor/implementation.md)。Agent 工具、run 级跨工具等待者计数与真实 Agent 验收后续另做。

全局 SQL 首次保存或修改表达式需要一个已绑定记忆空间来编译；已有同作用域、已知分类的宏只改名称、启停和输出设置可在无活动空间时保存。

旧性能脚本已适配新端口，使用本地确定性向量、不请求 API。当前单次 1,000 条记录／两组／1024 维测量约 1.99 秒，含快照 1.11 秒、源准备与评分 0.81 秒、评分物化与 SQL 0.074 秒；采样最高 RSS 约 279 MiB。该 Node 单次样本不代表浏览器峰值或所有规模的保证，生产仍使用 10 秒总预算。
