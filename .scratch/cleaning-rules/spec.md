# 清洗规则

Status: 已确认（grilling 会话产出，见 apps/docs/adr/0001-cleaning-rules-apply-on-read.md）

## 目标

为 api/web 实现简单的正则清洗功能：记忆空间内按顺序执行的正则规则列表，每条以「保留」或「去掉」模式改写导入消息的内容，影响消息展示与填表任务输入。目的是在喂给 Agent 前去掉多余符号（类似 SillyTavern 的正则功能）。

## 已确认范围

- **读取时变换**：来源存储永远保存 JSONL 原始内容；读取时套用规则。改规则追溯生效，无需重新导入。
- **空间级**：每个记忆空间独立一份规则。
- **单列表 + 每行模式**：保留/去掉在同一有序列表任意穿插，按位置顺序执行，上一条输出是下一条输入。
- **语义**：
  - 保留 = 有匹配则内容替换为「捕获组 1（若有）否则整段匹配」的全局拼接；无匹配则原样不动。
  - 去掉 = 删除所有匹配段；无匹配同样原样不动。
- **引擎**：JS `RegExp`；flags 勾选 g/i/m/s/u/y，默认 g，允许取消。
- **每条规则**：名称、启用开关、模式、正则、flags。
- **UI**：MemoryWorkspace 内「清洗规则」面板 + 实时预览（前 10 条消息原文→变换后对照，前端本地纯函数渲染）；整面板草稿 + 单个保存按钮。
- **边界**：改规则不重置 processed 状态；清洗后为空的消息照常展示、照常进提示词；空匹配正则允许保存；正则语法错误必须拒绝（400）。
