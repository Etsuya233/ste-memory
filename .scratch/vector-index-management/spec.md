# 向量索引管理需求

状态：需求已确认，待开发。日期：2026-10-22。

本文由主代理与一个 GPT-6 Sol Medium 子代理按 Grill With Docs 方式分轮问答整理，并根据用户后续讨论更新。用户已确认四项基础能力、索引配置保存到预设，以及自动 / 预设 / 自定义三种配置来源方案。按最新讨论，任务模型调整为每条向量一项任务，增加筛选与手动优先机制；第 7 节的任务粒度与优先级顺序已由用户确认。本文独立定义目标行为，不依赖另一分支的实现或设计。

## 1. 目标和范围

用户能为每张记忆表格配置向量化方式，知道某条记录的哪些向量已经生成、哪些需要更新，并能观察和停止后台工作。记忆记录仍是原始业务数据，向量作为可随时删除和重建的派生索引保存在本地；向量服务失败不影响记录保存、填表或普通记忆查询。

本轮包含 embedding 连接配置、表级索引配置、输入预览、单条向量化、自动更新、全表补建与强制重算、状态展示、任务列表与取消，以及配置的备份和复用。语义检索、相似度排序、查询 Agent 检索工具、宏召回和生成前准备留待后续需求；本轮完成后可维护向量，尚不承诺改善实际召回效果。

配置、向量与任务按记忆空间隔离；同页去重不跨空间共享计算。派生向量与任务保存在当前浏览器站点的本地存储中，更换浏览器或站点地址后不能假定索引仍在，需从原始记忆和配置重建。

## 2. 配置与向量单位

每张表拥有独立的索引开关、配置来源、更新方式和向量分组。缺少索引配置的旧表和旧格式导入数据默认关闭索引，用户首次自行开启时默认选择手动更新；从包含索引配置的预设创建或应用表结构时，采用预设保存的开关、更新方式和分组。配置来源分为自动配置、使用预设配置、自定义配置，具体规则见下节；自动配置动态跟随启用字段，预设和自定义配置采用明确选定的字段列表。

### 配置来源与更新方式

配置来源回答“哪些字段如何组成向量”，更新方式回答“何时发起向量化”。两者独立：自动配置搭配手动更新时，只自动生成字段分组，仍需用户点击才请求 embedding；自定义配置搭配自动更新时，按用户定义的分组自动更新向量。界面将手工选择与编辑分组统一称为“自定义配置”，以免与“手动更新”混淆。

| 配置来源 | 生效规则 | 字段结构变化后的行为 |
| --- | --- | --- |
| 自动配置 | 全部当前启用的业务字段按表内定义顺序组成一个分组 | 字段新增、删除、启停或顺序变化后重新生成分组 |
| 使用预设配置 | 使用随表带入或用户明确导入的固定分组快照 | 不自动加入新字段，已选字段删除或停用时显示失效项 |
| 自定义配置 | 用户自行添加、删除分组，选择并排序字段，可跨组复用字段 | 不自动加入新字段，已选字段删除或停用时显示失效项 |

有随表带入的有效预设分组时，来源默认“使用预设配置”；没有预设分组时默认“自动配置”。该默认选择不自动开启索引，也不把手动更新改成自动更新。已有预设分组失效时仍保留来源并显示失效项，不自动改用其他来源。空间备份、镜像或克隆已有来源设置时，保留原选择。

### 自动配置

自动规则只读取当前表的启用业务字段，不包括内部身份、修订等系统元数据；不按字段名猜测业务含义，不调用 LLM，不引入长短字段阈值或隐式拆组。自动生成一个稳定分组，输入仍遵循第 3 节的统一格式。界面展示实际选中的字段、示例输入及长度检查，用户可直接转为自定义配置调整。

自动配置随已保存的字段结构变化重新生成分组，草稿结构不影响正式索引。只有生成输入或影响向量生成的有效配置变化时才需要更新向量；是否发请求仍取决于索引开关与更新方式。没有启用字段时允许保存自动规则，显示“暂无可用字段”并停止该表向量请求；它与某条记录组内无值的“无内容”区分展示。已移除分组或已变成空输入的旧向量在本地核对时清理，无需为清理发起远端请求。

全部字段合组后若某条记录超长，明确报告记录、分组与长度问题，引导用户转为自定义配置拆成多个分组。第一版不承诺自动规则适合所有表，也不在失败时暗中截断或切换算法。

### 预设配置与自建表

“使用预设配置”读取当前表持有的独立快照，不实时跟随预设库。创建或应用表格预设时带入相应快照；修改表或字段 Key 后，已实例化的快照继续按空间内身份关联，不因改 Key 丢失选择。

自建表没有快照时，可显式选择“从表格预设导入配置”，选择一个系统自带或用户预设及其中一张表。只按来源分组涉及的字段 Key 与当前表启用字段精确匹配，全部匹配后才允许保存；列出不存在或停用的字段，不做模糊匹配、自动建字段或手动映射，不保存半份配置。表名无需相同，导入不改变当前表结构、索引开关或更新方式。

导入后先预览映射到当前表的分组和实际输入，保存后复制为当前表的预设配置快照，与来源预设脱钩。未带入且未成功导入快照时，界面说明“尚无预设配置”，用户可导入或选择自动 / 自定义配置，不静默替换来源。需要更换快照时同样显式导入并保存。切换到自动或自定义来源后仍保留已有预设快照，供以后切回使用；原预设被改名或删除也不影响该快照。

### 自定义与来源切换

从自动或预设来源转为自定义时，将当前生效分组复制为可编辑草稿，无需从空白开始；没有可用字段时允许进入空草稿，但启用索引前须完成合法分组。自动与预设分组以只读方式呈现，选择编辑时转为自定义；编辑尚未保存前不影响正式配置。

来源切换、预设导入和草稿预览本身均不发起向量请求，保存前展示将生效的字段和需要更新的范围。离开尚未保存的自定义草稿时，说明草稿将丢失；保存自动或预设来源后，不额外保留一份隐藏的历史自定义规则，之后仍可从当前生效配置转为自定义。

保存来源切换不改变索引开关或更新方式。若实际输入、有效分组配置和模型未变，可复用现有向量；仅切换来源标签或修改分组名称，不使索引过期，也不解除同目标取消 / 失败抑制。字段名称进入实际输入，字段改名仍按输入变化处理。规则影响范围内的新目标按手动 / 自动更新方式决定是否提交，已提交项按第 7 节优先级调度。

本节三种来源的算法、预设导入、来源切换及另存预设固化规则已由用户确认。

### 向量分组

向量分组包含稳定身份、名称和有序来源字段列表。新建或修正分组时，组内至少选择一个当前表的启用字段；组内禁止重复选择同一字段，不同分组允许复用同一字段。已保存分组因字段删除或停用而失效时，保留失效项供修正，不阻止其他合法分组处理。配置按空间内字段身份绑定，修改字段 Key 不丢失选择。分组名称只用于界面识别，改组名或调整分组展示顺序不要求重新向量化。

例如，一张人物表可以配置如下两个分组：

| 分组 | 来源字段及顺序 | 一条记录的向量化结果 |
| --- | --- | --- |
| 人物背景 | 姓名、身份、背景 | 将这三个字段组合成一份输入，生成一个向量 |
| 人物近况 | 姓名、当前位置、当前状态 | 将这三个字段组合成另一份输入，生成一个向量 |

“姓名”在两组中重复使用。一条记录在两组均有内容时拥有两个向量；分组之间不做平均、拼接已有向量或共享状态。第一版每条记录每个分组最多生成一个向量，自动切片、重叠片段、公共上下文配置和智能分组暂不纳入。

## 3. 实际输入与配置校验

组内按配置顺序以“字段名：字段值”拼接输入，字段之间使用固定换行。预览展示将实际发送的完整文本、来源字段、长度检查结果和预计向量数量。预览可使用尚未保存的配置，并须标明草稿；预览和本地检查均不请求 embedding，配置保存后才影响正式索引。

空值和空列表跳过，数字 0 与布尔值 false 保留。整组无有效内容时显示“无内容”，不发请求，并清除该组先前的向量。多值字段保持确定的原始顺序；日期、数字、布尔值和选项使用确定的文本格式，预览与实际请求共用同一规则。

引用字段使用目标记录的显示文本，不发送内部记录 ID，也不递归复制目标完整内容。目标显示文本变化会改变输入；目标不存在或无法正常显示时，明确定位到记录与分组并报错。预设或自定义分组中的来源字段被删除或停用时，相应分组显示“配置失效”，停止该组向量化；系统保留失效项供用户修正。其他有效分组仍可处理。自动来源按已保存的启用字段集合重新生成分组，不将按规则排除字段视为配置失效。

输入超出模型支持长度时，该分组失败并显示长度及上限信息，用户可调整字段内容或拆成多个分组。禁止静默截断和隐式切片。具体长度单位与模型输入约束需在 embedding 接入验证时确定；不能把字符数冒充 token 数，也不能承诺未经验证的模型能力。

## 4. 连接设置

第一版使用一个插件级活动 embedding 连接，至少提供端点、认证和模型配置，并呈现已验证的输入约束。连接独立于填写与查询 Agent 的聊天连接，不自动把聊天模型当作 embedding 模型。设置明确说明：选中的字段文本会发送到该端点。

模型、端点或影响向量语义的参数发生变化时，已有索引标为需要更新；仅修改连接名称或轮换密钥不要求重算。不同模型产生的向量不能被标成当前模型的有效结果。连接未配置或不可用时，仍允许保存索引配置，表级显示“等待连接”或具体错误。连接可用性与已有向量有效性分开呈现：缺少可用连接不能把未生成目标显示成就绪；若目标模型仍明确且已有向量匹配，可以显示该分组已就绪，同时提示连接当前不可用。

具体服务适配、请求代理、模型标识、维度和长度检查能力是实施前的技术验证项。本文不预先承诺某个提供商已受支持，也不要求自动探测所有服务能力。服务响应数量、维度或数值不合法时明确失败。单次请求须有有限超时，超时后释放执行机会并显示错误，不能无限占住队列使当前对话无法处理；具体超时与批量参数在接入验证时确定。

## 5. 手动与自动向量化

### 手动更新

保存手动更新配置或在手动更新下保存记录，不创建新的向量请求任务；本地输入核对、状态更新和无效向量清理仍可执行。切换前已提交且未取消的任务继续按调度规则处理，可能发出后续请求，界面提示可以另行取消。用户在单条记录上点击“向量化”，可补齐缺失、过期、失败或被取消的分组；支持从记录详情对指定分组重试。输入和模型均匹配的就绪向量直接复用。

表级提供“补建 / 更新索引”，为所有需要更新的记录向量批量创建任务；另提供“强制重新计算”，忽略可复用结果并重新请求。强制重算在记录和表两个范围均可使用，并在执行入口说明将重新调用服务、可能产生费用。用户显式点击补建、向量化、重试或强制重算创建的任务均按手动来源调度，即使表的更新方式为自动。

### 自动更新

保存更新方式为自动的配置时，界面先明确显示保存后的存量处理范围，并提供输入预览。索引已启用、更新方式为自动且存在可执行目标时，保存成功后按向量目标批量创建自动任务。可执行目标须有合法分组、非空输入和可用连接，且确需更新、未被取消或失败抑制、未处于全局错误阻塞；尚无连接或配置失效时只展示相应等待或错误，不连续创建注定失败的任务。没有启用字段或没有需请求的非空目标时，只保存配置并更新本地状态，不发起向量请求，必要的旧向量清理由本地核对完成。配置来源为自动但更新方式为手动时，同样只保存规则。后续仅根据已保存的记录和配置更新索引：手动编辑、填写 Agent 提交等来源使用相同行为，网格草稿不触发请求。由记录保存、配置保存或空间激活自动产生的更新任务归为自动来源，用户编辑过记录不等于手动创建了向量任务。

同一记录的连续修改允许合并，只处理最新目标。修改未参加输入的字段不重新调用 embedding；字段名称参与输入，因此改名需要更新，字段 Key 未进入输入时改 Key 可复用结果。引用目标显示变化，在已保存数据提交后通过可合并的异步输入核对发现，无需建立复杂反向依赖系统。

自动表在空间激活、恢复和用户主动检查索引时核对缺失或过期目标。手动表同样可核对状态，但不自动请求。正常检查与已保存数据变更负责修复漏登记，不承诺数据提交与索引登记之间无丢失窗口，也不要求后台持续扫描未打开的所有空间。

自动构建遇到某个目标失败，或用户取消后该目标已无其他有效任务请求时，不因轮询、空间切换或页面重开而反复重试同一目标。显式重试，或该目标的实际输入、有效分组配置、模型发生变化后，才允许再次处理。与索引无关的修改不解除该限制；等待当前对话的优先任务完成也不属于失败或取消。

## 6. 索引状态展示

记录网格提供向量状态摘要，详情展示每个分组的状态、生成时间、模型、实际输入预览和可读错误。表级汇总展示记录数、就绪 / 待更新 / 异常数量和当前任务入口。状态以记录与分组为基础，任务结束状态单独展示。

| 索引状态 | 含义 |
| --- | --- |
| 未启用 | 表关闭索引 |
| 配置失效 / 等待连接 | 缺少合法配置或可用连接，暂时不能请求；表级连接状态与分组缓存有效性分开呈现 |
| 暂无可用字段（表级） | 自动配置下没有启用的业务字段，尚无可生成的分组，不请求向量 |
| 未生成 | 有输入，尚无向量 |
| 待更新 | 已有向量与当前输入、配置或模型不匹配 |
| 排队中 / 处理中 | 当前目标已加入任务或正在计算 |
| 已就绪 | 向量与当前已知输入、配置和模型匹配 |
| 无内容 | 组内没有可向量化内容，无需发请求 |
| 失败 | 当前目标缺少有效向量，且上次处理出错，展示原因及重试入口 |

取消和中断不等于成功：任务标为已取消或已中断，目标分组没有其他有效未结束任务时恢复为未生成或待更新，并显示对应原因；存在强制重算后继任务时，仍展示其实际排队状态。失败、取消或中断时已经生成的旧向量可以保留，但只能按其实际匹配情况显示。

一条记录存在多个分组时，显示“就绪 1/2，失败 1”等摘要，空组另外计数。存在失效、失败、缺失或过期的分组时，禁止把整条记录显示成完全就绪。全空记录显示“无内容”，有效非空分组全部就绪且其余为空时显示“已就绪”，并说明空组数量。强制重算失败或取消时，若旧向量仍与当前目标匹配，分组保留已就绪状态，另显示最近重算错误或取消提示；对应任务仍按实际结果显示失败或已取消，不能用任务状态覆盖有效索引状态。

## 7. 任务列表、调度与取消

### 一条向量一项任务

一项向量任务只处理一个记忆空间中一条记录的一个分组、一个确定的目标版本。目标版本由实际输入、影响向量生成的有效配置和模型确定。人物“张三”的背景组与近况组是两项任务，100 条记录各有 2 个非空且需要生成的分组时，最多创建 200 项任务。

全表补建或单条记录向量化只负责为所选范围批量创建这些任务，不另外生成父任务、操作级任务或共享订阅。操作结束提交时展示新建、复用、提升优先级、已就绪跳过、无内容及失效配置跳过的数量；之后通过筛选查看任务，不承诺按某次操作追踪所有复用目标。已经就绪且无需强制重算、无内容或无合法分组的目标不创建无意义的请求任务，状态与错误在索引界面体现。

任务的目标指纹创建后固定。排队期间或请求期间实际输入、有效配置或目标模型变化，或记录 / 分组被移除时，旧任务标为已失效；未发请求的不再请求，已发请求的迟到响应丢弃。自动更新可为最新指纹创建新任务，手动更新等待用户重新操作，包括强制任务。任务不在执行前悄悄改成另一个目标版本，也不无限追赶连续编辑。

### 去重、提升与强制重算

同页对相同空间、记录、分组及目标指纹的普通请求，已有未结束任务时复用该项，不生成多个展示任务或额外调用。用户显式向量化已有自动任务的目标时，把该任务来源提升为手动并提示“已提升为手动优先”；任务身份和目标不变，不保留多份请求归属。后续自动触发不将它降级。配置来源标签或等效分组身份变化不要求重算，也不能借此绕过同目标取消 / 失败抑制。

强制重算要求在本次显式操作后实际发出新的请求。同目标任务尚未发请求时，将其提升为手动并标记强制；已经发请求时，允许当前请求结束，另排一项唯一的强制后继任务。连续点击只复用已有待执行强制任务，并明确提示将有一次额外调用，不能用本次操作之前已发出的请求代替强制重算。普通请求到来时优先复用在途普通任务；只有待执行强制任务时复用该项，不清除强制意图，也不创建第三项任务。

在途任务和强制后继任务分别取消：取消前者不取消后继，取消后继不影响在途任务。除此例外，同目标最多保留一项未结束任务；不同目标指纹不能混用结果。重试失败、已取消、已中断或已失效项时，针对当前已保存数据生成新的任务，旧历史状态不改写；相同目标已有未结束项时仍按上述去重规则处理。

### 列表与筛选

在现有任务入口增加向量任务区域，与填表任务清楚区分。每行展示空间、表、记录显示文本、分组、来源（手动 / 自动）、普通 / 强制操作、状态、等待原因、创建 / 开始 / 结束时间、错误及取消或重试入口；详情可查看该任务目标输入、模型与版本。列表默认当前空间的未结束任务，支持空间（当前 / 全部 / 指定）、表、状态、来源筛选，并支持记录及分组文本搜索。切换空间后表筛选选项随空间范围更新，不留下无法解释的隐藏结果。

筛选仅改变展示，不改变队列、来源或优先级。提供清除筛选入口，以及当前筛选结果数和全局未结束 / 运行中 / 阻塞计数，避免把“筛选下无任务”误解为全部结束。列表分页或按需加载，活动任务不因分页或历史清理而丢失；终态历史采用明确数量上限，不沿用原操作级任务的每空间 20 条显示假设。具体分页量和保留上限在实施时确定，取消 / 失败抑制不随历史裁剪删除。

支持单项取消和勾选批量取消，批量操作只作用于明确选中的未结束任务，并显示数量；不隐式取消筛选外或尚未选中的任务。全表操作的结果按向量任务数量统计，没有部分成功的单项任务；记录和表级索引汇总仍按第 6 节呈现。

### 手动优先与当前对话优先

页内串行发送向量请求。先按手动 / 自动来源排序，同来源中再优先当前对话绑定的记忆空间，同等级按任务提交先后执行：

| 优先级 | 任务 |
| --- | --- |
| 1 | 当前空间的手动任务 |
| 2 | 其他空间的手动任务 |
| 3 | 当前空间的自动任务 |
| 4 | 其他空间的自动任务 |

这会将此前跨来源的当前空间优先调整为手动优先，具体顺序已由用户确认。同来源中，切换对话后的当前空间仍优先；两个对话绑定同一空间时无需改变空间优先级。没有绑定空间时，同来源按提交先后处理。用户显式创建任务、从自动提升为手动，以及切换对话后，均在下一次请求开始前重新排序。

已发出的单次请求允许结束并保存仍有效的结果，不因新手动任务或切换对话而中止。每次请求结束后重新选取最高优先级的可执行任务，不能等整表工作结束才切换。例如自动任务正在运行时，用户创建手动任务，当前请求结束后先处理手动队列；同为自动任务时，切到 B 后优先 B，再继续其他空间。

排队项显示实际等待原因，例如等待手动优先任务、等待当前空间同类任务或连接阻塞；优先级等待不属于取消、中断或失败，不产生重试抑制。第一版不要求额外的公平调度，低优先级可能等待较久。单次请求的批量保持适中；若接口批量发送多个向量，每项仍独立记录结果，取消某一项不应中止同请求中的其他有效任务。切换点仍是整个单次请求结束，不增加并发请求来绕过等待。收起面板或更改筛选不停止队列。

### 状态、取消与错误

| 任务状态 | 结果 |
| --- | --- |
| 排队中 | 等待执行，可带优先级等待或全局阻塞原因，可以取消 |
| 运行中 | 已发出请求、等待该向量结果，可以取消 |
| 成功 | 该任务目标向量已成功生成并保存 |
| 失败 | 该任务计算或保存失败，显示具体原因 |
| 已失效 | 目标输入、配置、模型或对象发生变化，不再执行或接收旧结果 |
| 已取消 | 用户停止该任务，迟到结果不写入 |
| 已中断 | 页面关闭、刷新或关闭表索引使任务无法继续 |

取消一项向量任务就停止该项；不再维护其他操作对该任务的共享请求归属。排队取消后不发请求；运行取消后尽可能中止网络请求，返回的该向量结果不写入。若该网络请求同时承载其他有效任务，只忽略已取消项的结果。取消不删除之前已保存的有效向量，也不停止其他记录、分组或强制后继任务。已发出的请求可能仍产生费用，界面立即反馈取消状态。

同目标没有其他有效未结束任务时，取消或失败抑制自动重新排队，轮询、切空间、重开页面和历史裁剪均不让相同目标复活。显式重试或强制重算可以解除所选目标抑制；输入、有效配置或模型变化可建立新的目标。已有强制后继不被前项取消或失败连带停止，后继成功后解除相应目标抑制。终态任务历史不因后来的成功改写。

单项局部失败不影响其他合法任务。鉴权、连接配置或存储容量等全局错误使当前项失败，尚未尝试的受影响项保持排队并显示阻塞原因，停止自动产生相同失败循环。连接错误阻塞使用该连接的请求，站点容量错误阻塞本地向量写入；其他合法本地操作不受影响。用户显式重试或修正条件后才重新尝试，强制任务同样遵循全局阻塞。修正密钥可以解除连接阻塞，但不使已有有效向量过期。

## 8. 重建、清理与页面中断

补建只计算缺失、过期和用户要求重试的目标，强制重算重新计算所选范围。均按记录、分组逐步保存结果，允许部分完成，无需保留两套完整索引或等待全表完成后统一发布。重建失败与取消保留已完成结果，用户修正后可以再次补建。

| 操作 | 预期行为 |
| --- | --- |
| 关闭表索引 | 停止该表全部未结束任务并标为已中断，保留配置与缓存，不新增取消抑制；再次开启且更新方式为自动时可核对并补建，先前显式取消或失败的抑制仍保留 |
| 清除向量索引 | 取消所选范围任务，删除向量及派生状态，保留记忆与配置；清除后不立即自动重建，需显式重建或后续目标变化 |
| 删除记录 / 表 / 空间 | 停止相应目标并清理派生数据，迟到响应不得重建已删除对象 |
| 清除空间记录 | 清除对应向量和任务，保留表级配置 |
| 应用表格预设 | 旧结构对应任务和索引失效，按新表身份与配置重新处理 |
| 页面刷新 / 关闭 | 未结束任务在下次打开时显示已中断，同一任务不自动续跑；已完成向量保留 |

索引已启用且更新方式为自动时，在页面重新打开、空间激活后可为可执行目标创建新的补建任务，处理未完成且未被取消或失败抑制的目标；手动更新等待用户操作，无可用字段时不创建请求任务。页面关闭后不继续后台网络执行，不要求浏览器后台服务。清除索引的自动重建抑制应有独立记录，防止被删除的派生状态导致立即重新构建。

响应落地前进行简单检查：空间、表、记录和分组仍存在，索引仍启用，该向量任务仍允许接收结果，当前输入、影响向量生成的有效配置和模型仍与任务目标指纹匹配。发现变化就丢弃旧结果。当前对话切换不改变任务的空间归属，也不作为丢弃响应的条件。分组改名、分组展示排序及手动 / 自动更新方式切换不影响输入时，可以接收当前请求结果；更新方式切换只影响后续自动提交，已提交任务按调度规则继续，界面说明可另行取消。接受检查之间仍存在短暂竞态和部分更新，后续检查或重建负责修复。

本轮不要求记忆写入与任务登记共享事务、全表原子切换、跨标签页租约、分布式锁或严格一次执行。多个页面可能重复请求，界面与文档不得承诺绝无重复调用或重复费用。此处简化只针对派生索引，不改变记忆保存、备份恢复和应用预设原有的数据规则。

## 9. 保存与复用边界

表级配置属于记忆空间的表结构。空间备份、对话文件镜像和克隆完整保留配置来源、生效规则及表持有的预设快照，包括暂未启用的预设快照，自动来源恢复后继续跟随字段变化；表格预设保存可复用的固定默认分组，具体规则见下文。空间实例按字段身份保存，克隆时分组和快照涉及的字段身份一并转换；预设按字段 Key 表达，实例化时转换身份。修改原预设不追溯改变已有空间。旧备份、旧镜像和旧预设缺少配置时视为关闭索引。

系统自带预设和用户预设共用同一套表级索引配置结构与校验规则。每张预设表可声明索引开关、手动 / 自动更新方式、向量分组名称与顺序、组内来源字段 Key 及顺序，同一字段 Key 可以在多个分组中复用。配置必须明确保存到预设内容中，不依靠表名或字段名推测分组，不为某个系统自带预设建立专用配置逻辑。

将当前空间另存或覆盖为用户预设时，保存各表的索引开关、更新方式和当时生效的完整分组；自动来源也固化为当时选中的字段快照，不导出对原空间或原预设的实时关联。保存界面说明“自动配置将保存为当前分组快照”。原空间仍保持原来源；从带有分组的新预设创建或应用表结构后，来源默认“使用预设配置”，新增字段需主动加入，用户也可重新选择自动来源。自动配置没有可用字段而无法形成合法固定分组时，启用索引的表须先补充字段或关闭索引后保存；已关闭索引的表允许保存为无分组配置，实例化后索引仍关闭，来源默认自动。不会生成虚假的空分组。

预设复制、导出和导入保留上述固定配置。另存或覆盖预设前校验分组字段，引用已删除或停用字段的失效组须先修正或移除；关闭索引也不能将无法匹配的旧字段身份当作字段 Key 保存，禁止静默丢弃失效项。预设编辑界面支持查看和修改配置，字段选择只能引用该预设表内存在且启用的字段。创建空间或应用预设时，为分组创建属于新空间实例的身份，并把字段 Key 转换为新字段身份，保留分组顺序、字段顺序和跨组复用关系；无法匹配字段时明确报错，禁止静默丢弃配置。

本轮建立上述统一配置契约、保存与实例化能力，为后续给系统自带预设编写默认向量分组提供基础。具体哪些系统表默认启用、选择哪些字段及采用何种更新方式，在后续默认配置标准中确定。未来新增内置默认配置只影响之后基于该预设创建或重新应用的表结构，已有空间继续保留自己的配置。预设库保存、编辑、复制、导入和导出本身均不发起向量请求，实际执行遵循实例化后的索引开关与更新方式。

向量、任务历史、执行进度及取消 / 失败抑制属于当前环境派生数据，不随备份、镜像、克隆或预设导出。embedding 凭据保存在插件本地连接设置中，不进入空间或预设文件。同一环境刷新需要保留抑制记录；恢复覆盖本地空间时，停止该范围旧任务并清除其旧派生索引与目标抑制，新建 / 克隆空间同样从无索引状态开始；未被恢复覆盖的空间不受影响。目标环境的连接或容量阻塞仍按实际情况保留，不能通过恢复空间绕过。

恢复或克隆配置后，索引已启用、更新方式为自动、存在可执行目标且当前环境连接可用时允许自动补建；缺少连接时显示等待，无可用字段时显示对应状态。已有导入、应用预设等操作界面或结果须说明自动更新可能触发远端调用，无需另建一套确认流程。数据库升级只迁移本地结构和兼容默认值，不在升级阶段发请求。

## 10. 验收场景

| 场景 | 通过标准 |
| --- | --- |
| 单条手动向量化 | 手动更新下保存配置和编辑记录不创建新请求任务；点击向量化后生成对应分组结果，先前已提交任务可继续且界面有说明 |
| 多字段合组与复用 | 姓名可同时存在于背景组与近况组，每组输入正确，一记录获得两个独立向量 |
| 空值与长文本 | 空组不请求；0 / false 不丢失；超长组明确失败，无截断或隐式分片 |
| 自动更新 | 已保存的输入变化触发更新，草稿和无关字段修改不产生新请求 |
| 自动配置与更新方式独立 | 自建表可自动生成分组；搭配手动更新时不因生成规则而请求，搭配自动更新时按生效输入更新 |
| 自动字段变化 | 启用业务字段按定义顺序形成一组，已保存的增删 / 启停 / 排序变化动态重算；零字段显示暂无可用字段且不请求 |
| 自建表导入预设配置 | 显式选预设表后按字段 Key 精确映射，缺失或停用项逐个报告且不保存半配置；成功后持有独立快照，不改变表结构和更新方式 |
| 来源切换与编辑 | 转自定义复制生效分组，预览草稿不请求；保存后仅实际输入或有效配置变化使索引待更新，来源 / 分组标签变化不解除取消抑制 |
| 引用与结构变化 | 引用显示变化能被异步核对发现；预设 / 自定义分组的来源字段删除或停用后显示配置失效，自动配置按启用字段重算 |
| 局部失败 | 成功组保留，失败组可定位和重试，记录摘要不误报全部就绪 |
| 向量任务粒度 | 100 条记录各有 2 个待生成非空组时最多建立 200 项任务，每项明确空间、记录、分组和目标版本，无父任务 |
| 重复请求与手动提升 | 同目标普通请求复用一项未结束任务；手动触发已有自动项后提升来源与优先级，不额外计算或保留共享归属 |
| 强制重算排队 | 未发请求的同目标项可升级强制；已发请求时只追加唯一强制后继，重复点击不堆积，旧请求不充当本次强制结果 |
| 目标版本固定 | 排队或运行中目标变化均使旧项失效，自动更新可为新指纹建任务，手动更新等待重新操作，不在旧任务内偷换输入 |
| 批量操作反馈 | 按向量报告新建、复用、提升及各类跳过数量；单项只有成功或失败等原子结果，不生成部分完成 / 部分失败任务状态 |
| 重算失败与有效缓存 | 强制重算失败但旧向量仍匹配时，分组仍就绪并附最近错误，任务显示失败，旧结果保留 |
| 独立取消 | 取消某向量任务不停止其他记录、分组或强制后继；批量请求中只忽略取消项结果，其他有效结果可保存 |
| 取消后再检查 | 同目标无其他未结束任务时，取消目标不因轮询、切空间、刷新及历史裁剪复活；显式重试 / 强制或目标变化可再处理 |
| 模型或配置切换 | 不兼容缓存变为待更新，旧响应不覆盖新目标，密钥轮换不触发全量重算 |
| 重建与清除 | 补建可复用，强制重算重新请求；清除索引保留原始记忆且不立即自动重建 |
| 手动优先 | 当前手动、后台手动、当前自动、后台自动依次处理，新增手动项在当前请求结束后优先，无需等自动队列处理完 |
| 同来源当前对话优先 | 同为手动或同为自动时优先当前空间；同来源同空间按提交先后，共享空间的对话切换不改变空间优先级 |
| 筛选与分页 | 可按空间、表、状态、来源及记录 / 分组搜索筛选，分页和清除筛选不改变队列；无匹配时仍能看到全局任务计数 |
| 等待状态与关页 | 排队项说明优先级或全局阻塞原因，保持可取消且不产生重试抑制；关页后未结束项中断，已生成结果保留 |
| 请求超时 | 单次请求超时可结束并释放执行机会，显示错误，不无限挡住当前空间 |
| 删除与恢复 | 删除后迟到结果不复活对象；恢复配置可重建，旧格式默认关闭，向量和凭据不随空间导出 |
| 预设配置往返 | 当前表配置另存 / 覆盖为用户预设后，复制、导出、导入均保留索引开关、更新方式、分组与字段顺序及跨组复用关系，操作本身不发请求 |
| 自动配置另存与恢复 | 另存预设固化当前分组，原表仍自动，新空间采用固定预设配置；空间备份 / 镜像 / 克隆保留原来源，自动模式恢复后仍动态跟随字段 |
| 快照保留与零字段 | 离开预设来源后仍可切回原独立快照；自动零字段表关闭索引后可另存无分组预设，创建后仍关闭 |
| 同身份空间恢复 | 恢复覆盖原空间后旧任务、向量和目标抑制不残留，其他空间不受影响，按恢复配置重新处理 |
| 预设实例化 | 系统自带预设与用户预设使用同一配置契约；创建空间 / 应用预设后字段和分组身份正确转换，配置独立，预设后续修改不传播到已有空间 |
| 默认配置扩展基础 | 可通过统一预设配置声明各系统表的默认分组，无需专用表逻辑；未声明配置的旧预设保持关闭索引 |
| 错误与轻量边界 | 服务或容量错误可见且不阻断记录保存，允许部分完成，未引入强一致性要求 |
| 全局错误阻塞 | 鉴权 / 容量错误停止受影响请求，未尝试目标仍可见，自动核对不反复建失败任务；修正条件或显式重试后可恢复 |

## 11. 确认范围与实施前验证

用户已确认：自动 / 手动向量化与可观察状态，表级字段组合和复用，可重建的轻量索引，任务可观察与取消，单次请求结束后切换调度，配置保存到表格预设，以及自动 / 预设 / 自定义来源独立于更新方式。自动来源采用启用业务字段一组，自建表可精确导入预设分组，另存预设固化当时分组，空间备份保留动态来源。

本次任务调整稿按用户最新方向，将按操作展示及共享归属替换为每个向量目标一项任务，并增加筛选。普通目标去重为一项，用户手动触发时提升既有自动项；强制操作保留在途请求之后最多一项后继。排队和运行期间目标指纹均不漂移，取消只作用于该向量任务，不再需要操作级部分完成、部分失败或父任务。该模型与细化边界已由用户确认。

优先级确认为“手动优先，同来源再当前空间优先”，即当前手动 > 后台手动 > 当前自动 > 后台自动。该顺序会替换此前跨来源的当前空间优先，已由用户确认；单次请求结束后重新调度的已确认边界保留。

实施前仍需验证 embedding 连接的可用请求路径、支持模型、维度、输入长度检查方法，以及单次请求超时与适当批量。验证结果须先明确可支持的连接与输入约束，再编写对应接入；未验证项不视为现有能力。具体系统自带预设的默认分组标准在后续制定。本需求作为后续开发与验收依据。
