状态：**评审用原型，不进构建**。只讨论 UI 信息架构与交互，不改数据结构、领域规则和验收脚本。

## 怎么看

直接双击 `prototype.html`，或在仓库根目录起一个静态服务后访问。无外部依赖，无构建步骤。

```powershell
python -m http.server 8788
# http://localhost:8788/.scratch/ui-tables-redesign/prototype.html
```

页面顶部可以：

- 在 **01 结构工作台 / 02 表格库 / 03 单表聚焦** 之间切换；
- 切换 **手机 / 桌面** 预览尺寸；
- 打开 **外观**，试深/浅主题、强调色、字体、字号；
- **重置数据** 把原型里的开关、改名、新建/删除恢复初始状态。

## 三个方向

### 01 结构工作台（推荐）

左侧表格索引，右侧当前表的「字段 / 表格信息 / 显示策略」。桌面双栏，手机两级钻取（列表 → 详情）。

- 一屏只展开一张表，页面高度不随表格数量增长；
- 表级操作收进页签与「⋯」，字段行只留开关，排序工具只在「管理字段」时出现；
- 桌面左右两个区域独立滚动；手机进入详情后只有详情内部滚动。

### 02 表格库

卡片墙展示全部表格（桌面三列 / 手机两列），点击卡片从右侧打开检视器。

- 先看全貌，再进入单表编辑；
- 卡片只保留启用开关与「⋯」，去掉四颗常驻按钮；
- 检视器复用 01 的详情结构。

### 03 单表聚焦 · 字段矩阵

表名下拉切换当前表，字段以矩阵呈现；表格信息与显示策略收进弹层。

- 垂直高度最小，一屏能看到全部字段；
- 字段行内只有开关，点击行才进入编辑；
- 「管理」时矩阵切换成排序模式，只显示字段名、上下移动和开关。

## 共同规则

1. 一次只展开一张表；列表只负责导航，不承载编辑器。
2. 表级操作 = 启用 + 一个「⋯」；字段级操作 = 行内开关 + 点击行编辑。
3. 危险操作离开主路径：删除收进表格信息页底部或操作菜单。
4. 滚动发生在单个区域内部（列表 / 详情 / 矩阵），而不是整页无限增长。

## 文件

- `prototype.html`：评审外壳、图标 sprite、外观控件；
- `prototype.css`：墨灰令牌 + 三个方向的布局与组件；
