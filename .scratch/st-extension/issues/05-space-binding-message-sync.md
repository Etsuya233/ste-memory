# 05 — 空间绑定与消息同步

**What to build:** ST 环境适配器（getContext 包装 + 事件桥：MESSAGE_SENT / MESSAGE_RECEIVED / CHAT_CHANGED）；记忆空间绑定与同步游标存 chatMetadata（随对话文件走，重命名不丢）；首次打开对话自动创建记忆空间并从共享包安装七张系统表；新消息按同步楼层自动追加、切对话对账补尾巴；向 UI 提供「按楼层跳转 ST 消息」能力（证据楼层 chip 的底层）。

**Blocked by:** 01 — 系统表模板收编共享包；02 — 插件工程骨架与构建链；03 — Dexie 持久层（一）

**Status:** ready-for-agent

- [ ] 打开已有对话自动建空间、七张系统表就位；再次打开不重复建
- [ ] 重命名对话后绑定不丢（chatMetadata 指针生效）
- [ ] 新消息（用户/AI）自动追加为同步楼层；切对话对账补尾巴
- [ ] 对账/游标推进为纯函数并有测试；手动验收：真实 ST 中跑通全流程
- [ ] 群聊：按对话文件绑定与同步（群聊有 chatId）；空间名 = 「群聊 - 对话文件名」（群聊无角色名）
- [ ] chatId 为 undefined（临时/未保存对话）：跳过绑定与同步，面板提示「当前对话未保存，暂不支持记忆」，不报错
- [ ] 对话重命名：绑定跟随（chatMetadata 在文件内），空间显示名保持创建时值；跨角色同名对话文件互不冲突（绑定靠指针，名字只是显示）
