# 04 — 完成字段类型和显示策略编辑器

**Type:** task

**What to build:** 为系统表和自定义表提供字段定义编辑器，覆盖约定的常见类型、必填规则、固定选项、字段 Prompt、字段开关、顺序和记录显示策略。

**Blocked by:** 03 — 创建和配置用户自定义记忆表

**Status:** ready-for-agent

- [ ] 支持短文本、长文本、自由短文本列表、整数、小数、布尔、日期、日期时间、单选、多选、单引用、多引用。
- [ ] 单选和多选字段可配置固定选项；引用字段只能引用同一记忆空间内的指定表。
- [ ] 字段支持必填、启用/停用、字段 Prompt 和显示顺序。
- [ ] 字段类型在 v1 创建后不可修改；删除字段为物理删除并要求确认。
- [ ] 每张表可以指定短文本显示字段，或配置基于字段的派生显示模板。
- [ ] 新增字段、修改字段定义和删除字段均有清晰的校验错误，不破坏已有合法记录。
- [ ] 停用必填字段时给出警告；手动编辑仍能查看和处理已有值。
