# 04 — 完成字段类型和显示策略编辑器

**Type:** task

**What to build:** 为系统表和自定义表提供字段定义编辑器，覆盖约定的常见类型、必填规则、固定选项、字段 Prompt、字段开关、顺序和记录显示策略。

**Blocked by:** 03 — 创建和配置用户自定义记忆表

**Status:** resolved

- [x] 支持短文本、长文本、自由短文本列表、整数、小数、布尔、日期、日期时间、单选、多选、单引用、多引用。
- [x] 单选和多选字段可配置固定选项；引用字段只能引用同一记忆空间内的指定表。
- [x] 字段支持必填、启用/停用、字段 Prompt 和显示顺序。
- [x] 字段类型在 v1 创建后不可修改；删除字段为物理删除并要求确认。
- [x] 每张表可以指定短文本显示字段，或配置基于字段的派生显示模板。
- [x] 新增字段、修改字段定义和删除字段均有清晰的校验错误，不破坏已有合法记录。
- [x] 停用必填字段时给出警告；手动编辑仍能查看和处理已有值。

## Answer

已完成字段定义与显示策略的 Core 规则、SQLite 持久化、HTTP CRUD 和 Web 编辑器。字段类型创建后锁定；固定选项、同空间引用目标、字段顺序和显示策略均由 Core 校验；显示策略使用稳定字段 ID，引用中的显示字段不能直接删除。停用必填字段会保留字段和值语义，并返回可展示警告。

自动化测试覆盖全部 12 种字段类型、固定选项、跨空间引用拒绝、类型不可变、字段更新/删除、显示策略依赖、迁移与浏览器 CORS。完整 typecheck、lint、格式检查、测试和构建通过；浏览器验收覆盖桌面、375px 窄屏、字段创建、显示策略保存和刷新后的持久化读取。
