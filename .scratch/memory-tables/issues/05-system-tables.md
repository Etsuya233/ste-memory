# 05 — 初始化七张系统记忆表及默认 Prompt

**Type:** task

**What to build:** 为每个新记忆空间初始化七张系统表：人物、人际关系、地点、物品、剧情、伏笔、待办，并写入固定字段、引用关系、默认显示策略和可编辑默认 Prompt。

**Blocked by:** 04 — 完成字段类型和显示策略编辑器

**Status:** resolved

- [x] 新空间自动拥有且只拥有一份系统表定义，系统表可像普通表一样启用/停用。
- [x] 人物表包含名称、别名、身份/定位、性格特征、外貌特征、背景/经历、当前状态、备注。
- [x] 人际关系表包含人物 A、人物 B、关系描述、当前状态、关键事实、备注，并使用单/多引用字段。
- [x] 地点表包含名称、地点类型、详细地点文本、当前状态、相关人物、相关物品、备注。
- [x] 物品表包含名称、物品类型、持有者/所属人物、当前位置、状态、关键属性、备注。
- [x] 剧情表包含名称、详情、相关人物、相关地点、状态、备注。
- [x] 伏笔表包含名称、详情、相关人物、相关地点、状态、计划回收信息、备注；待办为独立表。
- [x] 待办表包含名称、详情、相关人物、相关地点、优先级、状态、截止日期、备注。
- [x] 关系显示文本可由人物 A/B 派生；系统表字段和 Prompt 均可被用户调整。

## Answer

新记忆空间会在一个 SQLite 事务内复制人物、人际关系、地点、物品、剧情、伏笔和待办七张系统表，并通过 `systemKey` 保持稳定身份和空间内唯一性。各表使用本票明列字段；人物 A/B、持有者、位置和各类“相关”字段配置为对应的单引用或多引用，关系显示模板为 `{人物 A 字段 ID} <-> {人物 B 字段 ID}`，其余表使用必填名称字段显示。

剧情、伏笔和待办状态沿用已确认 Prompt 草案中的固定选项，待办优先级为高/中/低，截止日期为日期字段。七张表都有可编辑中文表 Prompt，当前状态、关系方向、引用、状态枚举和截止日期等易混淆字段带有可编辑字段 Prompt；表格及字段继续使用统一编辑服务和开关规则。
