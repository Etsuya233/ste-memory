# 05 — 初始化七张系统记忆表及默认 Prompt

**Type:** task

**What to build:** 为每个新记忆空间初始化七张系统表：人物、人际关系、地点、物品、剧情、伏笔、待办，并写入固定字段、引用关系、默认显示策略和可编辑默认 Prompt。

**Blocked by:** 04 — 完成字段类型和显示策略编辑器

**Status:** ready-for-agent

- [ ] 新空间自动拥有且只拥有一份系统表定义，系统表可像普通表一样启用/停用。
- [ ] 人物表包含名称、别名、身份/定位、性格特征、外貌特征、背景/经历、当前状态、备注。
- [ ] 人际关系表包含人物 A、人物 B、关系描述、当前状态、关键事实、备注，并使用单/多引用字段。
- [ ] 地点表包含名称、地点类型、详细地点文本、当前状态、相关人物、相关物品、备注。
- [ ] 物品表包含名称、物品类型、持有者/所属人物、当前位置、状态、关键属性、备注。
- [ ] 剧情表包含名称、详情、相关人物、相关地点、状态、备注。
- [ ] 伏笔表包含名称、详情、相关人物、相关地点、状态、计划回收信息、备注；待办为独立表。
- [ ] 待办表包含名称、详情、相关人物、相关地点、优先级、状态、截止日期、备注。
- [ ] 关系显示文本可由人物 A/B 派生；系统表字段和 Prompt 均可被用户调整。
