# 11.5 — QueryAgent 调试聊天界面

**Type:** task

**What to build:** 在每个记忆空间提供一个简单聊天界面，可对本记忆空间内容提问，并实时展示思考过程与工具调用参数/结果，主要用于调试 11 的 QueryAgent。

**Blocked by:** 11 — 实现 Agent 引擎与 QueryAgent

**Status:** ready-for-agent

- [ ] 每个记忆空间一个聊天面板：输入提问、接收流式回答，消息历史保留在页面内。
- [ ] 实时展示思考过程与工具调用参数/结果（消费 11 流式端点事件：turn、message、tool_execution），工具结果可展开/收起。
- [ ] LLM 配置表单：Base URL / API Key / model；留空字段由服务端环境变量回退并标注生效来源（网页配置 / 环境变量）；API Key 仅保存在当前页面内存（刷新即失，不写 localStorage/sessionStorage/数据库）；Base URL、Model 等非敏感配置可保存浏览器本地。
- [ ] 提问中可取消（AbortController）；网络错误、LLM 鉴权失败、超时等有明确提示，不阻塞继续操作。
- [ ] 不提供提案相关 UI（范围选择、提案面板、确认提交随提案流归入 12 及后续）。

## Comments

### 拆分说明

由原「11.5 Web 提案界面」重定向而来：提案界面内容（范围选择、提案面板、确认提交）随提案流顺延到 12 及后续；LLM 配置表单需求移入本 Ticket（聊天要跑通需要配置）。

调试价值：通过聊天界面观察 QueryAgent 的查询路径——是否先查再答、查了正确的表/字段、条件是否正确；工具调用参数与结果实时可见，便于迭代提示词与工具设计。
