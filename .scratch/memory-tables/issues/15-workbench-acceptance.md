# 15 — 完成记忆工作台并通过 1K+ 验收

**Type:** task

**What to build:** 将上传、表配置、记录编辑、Agent 预览/提交、任务控制、历史和原始聊天对比串成桌面端实验工作台，并完成面向 1K+ 楼层的端到端验收和失败路径覆盖。

**Blocked by:** 14 — 提供任务轮询、暂停、恢复和中止

**Status:** ready-for-agent

- [ ] 三栏工作区可在左侧管理表/字段/Prompt/开关，中间浏览和手动编辑当前记录，右侧查看记录、证据、历史和原始消息。
- [ ] 用户可从创建空间开始完成 JSONL 上传、选消息范围、预览、确认提交、轮询任务和查看结果的完整流程。
- [ ] 任务运行时能实时查看已写入的上一批结果，并显示目标空间只读状态。
- [ ] 手动 CRUD、引用删除限制、历史只读、证据跳转和任务失败/中止/重启恢复均有界面入口和错误提示。
- [ ] 使用至少 1,000 条消息的 JSONL 完成上传、范围处理、查询、批次写入和原始消息定位测试。
- [ ] 验收记录包含 Agent 提取质量的人工对比，不把质量评估伪装成自动正确性断言。
- [ ] 覆盖 API、Application、SQLite 事务、Source Store、任务状态机和 Web 关键流程测试。
- [ ] 检查所有代码文件不超过 300 行，补齐必要注释和本地运行文档。
