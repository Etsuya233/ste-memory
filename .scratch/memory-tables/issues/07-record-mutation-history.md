# 07 — 更新和物理删除记录并保存只读历史

**Type:** task

**What to build:** 实现当前记录的手动更新、删除和历史快照。每次更新或删除必须先保存旧状态，使用同一 `revision_id` 标记同一批原子变更；历史只读，不提供恢复。

**Blocked by:** 06 — 创建和浏览当前记忆记录

**Status:** ready-for-agent

- [ ] 更新支持字段级 patch、显式置空和 `expected_revision_id` 并发校验。
- [ ] 删除当前记录为物理删除，删除前保存完整旧记录快照。
- [ ] 更新前保存完整旧记录快照，再写入新当前记录。
- [ ] 同一原子批次跨表变更共享一个 `revision_id`，并记录 user/agent 来源、原因字段由记录自身承载、时间信息。
- [ ] 历史记录不可编辑、不可删除、不可恢复，只支持按表、记录、revision 和时间过滤。
- [ ] 页面可从当前记录打开历史列表和快照详情。
- [ ] 并发版本冲突不会覆盖他人更新，并返回可理解的错误。
