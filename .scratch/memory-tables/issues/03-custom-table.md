# 03 — 创建和配置用户自定义记忆表

**Type:** task

**What to build:** 在单个记忆空间内提供用户自定义表的创建、浏览、重命名、启用/停用和物理删除，并支持表级 Prompt；表定义只影响所属空间。

**Blocked by:** 02 — 上传 JSONL 并创建可浏览的记忆空间

**Status:** ready-for-agent

- [ ] 用户可创建一个没有系统表依赖的空自定义表。
- [ ] 表名称和描述可编辑，表可启用或停用。
- [ ] 表级 Prompt 可保存、读取和修改，并在该空间中生效。
- [ ] 删除表是物理删除，删除前需要明确确认，删除后不能通过历史功能恢复。
- [ ] 不同记忆空间中同名表互不影响。
- [ ] 左侧工作区可列出表，并显示启用状态。
- [ ] 空表仍可进入字段配置和数据查看页面。
