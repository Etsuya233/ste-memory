# 03 — 创建和配置用户自定义记忆表

**Type:** task

**What to build:** 在单个记忆空间内提供用户自定义表的创建、浏览、重命名、启用/停用和物理删除，并支持表级 Prompt；表定义只影响所属空间。

**Blocked by:** 02 — 上传 JSONL 并创建可浏览的记忆空间

**Status:** resolved

- [x] 用户可创建一个没有系统表依赖的空自定义表。
- [x] 表名称和描述可编辑，表可启用或停用。
- [x] 表级 Prompt 可保存、读取和修改，并在该空间中生效。
- [x] 删除表是物理删除，删除前需要明确确认，删除后不能通过历史功能恢复。
- [x] 不同记忆空间中同名表互不影响。
- [x] 左侧工作区可列出表，并显示启用状态。
- [x] 空表仍可进入字段配置和数据查看页面。

## Answer

已完成统一记忆表格模型中的自定义表切片，覆盖 Core 应用服务、SQLite 持久化、HTTP CRUD 和三栏 Web 工作台。表定义按 `memory_space_id` 隔离，支持名称、描述、Prompt、启用状态和物理删除；空表可以进入数据查看与字段配置页。

Core 与 HTTP/SQLite 自动化测试覆盖创建、更新、空间隔离和物理删除。完整类型检查、lint、格式检查、测试与构建通过；浏览器验收覆盖桌面、移动端、配置持久化和删除确认。
