# 06 — 创建和浏览当前记忆记录

**Type:** task

**What to build:** 实现正式表中的当前记录读写基础能力和工作区表格视图，用户可以按表格查看、搜索、分页、查看详情并手动创建记录。

**Blocked by:** 05 — 初始化七张系统记忆表及默认 Prompt

**Status:** resolved

- [x] 每条记录具有不可变的内部记录 ID；显示字段值不要求唯一。
- [x] 记录按字段定义存储结构化 JSON payload，并按字段类型进行读取和校验。
- [x] 表格视图显示配置的显示文本、关键字段和稳定记录 ID。
- [x] 支持分页、基础搜索、记录详情和空状态。
- [x] 手动创建记录校验必填字段、选项值、日期/数值/布尔格式和引用目标。
- [x] 手动创建可记录来源时间和来源定位；没有来源时明确标记为手动记录。
- [x] 停用字段不会从已有记录中静默删除；查看详情可看到其原值。

## Answer

当前记忆记录使用不可变记录 ID 和独立修订 ID，动态字段值按字段 ID 保存为 JSON payload。Core 在创建和读取时执行受控字段类型校验，并校验必填值、选项、日历日期、日期时间和同一记忆空间内的引用目标；手动创建的修订来源标记为 `user`。SQLite 使用统一 `memory_records` 表保存 payload、显示文本、来源、修订信息和时间元数据。

HTTP 提供记录创建、分页搜索、列表和详情接口。工作区数据页提供搜索、分页、空状态、结构化手动创建和引用 ID 输入，网格展示配置的显示文本、关键字段、稳定记录 ID 与来源；右侧检查器可在记录详情和原始聊天间切换，并明确展示手动记录、来源时间、来源定位及停用字段的原值。
