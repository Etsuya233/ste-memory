# 06 — 创建和浏览当前记忆记录

**Type:** task

**What to build:** 实现正式表中的当前记录读写基础能力和工作区表格视图，用户可以按表格查看、搜索、分页、查看详情并手动创建记录。

**Blocked by:** 05 — 初始化七张系统记忆表及默认 Prompt

**Status:** ready-for-agent

- [ ] 每条记录具有不可变的内部记录 ID；显示字段值不要求唯一。
- [ ] 记录按字段定义存储结构化 JSON payload，并按字段类型进行读取和校验。
- [ ] 表格视图显示配置的显示文本、关键字段和稳定记录 ID。
- [ ] 支持分页、基础搜索、记录详情和空状态。
- [ ] 手动创建记录校验必填字段、选项值、日期/数值/布尔格式和引用目标。
- [ ] 手动创建可记录来源时间和来源定位；没有来源时明确标记为手动记录。
- [ ] 停用字段不会从已有记录中静默删除；查看详情可看到其原值。
