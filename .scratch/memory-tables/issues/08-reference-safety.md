# 08 — 实现跨表引用和删除安全

**Type:** task

**What to build:** 实现单引用、多引用的同空间记录关联，并在被引用记录删除时阻止操作，要求先解除引用或在同一原子批次中转移引用后再删除。

**Blocked by:** 07 — 更新和物理删除记录并保存只读历史

**Status:** resolved

- [x] 引用值只保存稳定的同空间内部记录 ID，不依赖显示名称。
- [x] 单引用和多引用均能在表格、详情、编辑器中选择同空间目标。
- [x] 引用目标不存在、跨空间或类型不匹配时拒绝写入。
- [x] 删除仍被当前记录引用的目标时返回阻止原因和引用位置。
- [x] 解除引用、转移引用、删除目标可作为一个跨表原子 MutationBatch。
- [x] 引用删除安全与 Agent 写入、用户手动写入使用同一校验逻辑。
- [x] 历史快照中的引用值保持当时的记录 ID，不因当前记录变化而改写。

## Answer

Core 在统一记录变更管线中构造 MutationBatch 最终态，引用目标校验同时约束同一记忆空间和配置的目标表。删除目标前会扫描最终当前记录，仍有引用时返回目标记录 ID 及引用表格、记录、字段位置；同批次解除或转移引用后可以原子删除，用户与 Agent 变更共享该校验。历史快照继续保存归档时的记录 ID。

Web 为单引用和多引用加载同空间目标表的完整候选，编辑器提交稳定 ID，表格、详情与历史使用显示文本和 ID 展示引用。HTTP 将删除阻止映射为 409，并保留结构化引用位置。
