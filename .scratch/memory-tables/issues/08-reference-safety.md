# 08 — 实现跨表引用和删除安全

**Type:** task

**What to build:** 实现单引用、多引用的同空间记录关联，并在被引用记录删除时阻止操作，要求先解除引用或在同一原子批次中转移引用后再删除。

**Blocked by:** 07 — 更新和物理删除记录并保存只读历史

**Status:** ready-for-agent

- [ ] 引用值只保存稳定的同空间内部记录 ID，不依赖显示名称。
- [ ] 单引用和多引用均能在表格、详情、编辑器中选择同空间目标。
- [ ] 引用目标不存在、跨空间或类型不匹配时拒绝写入。
- [ ] 删除仍被当前记录引用的目标时返回阻止原因和引用位置。
- [ ] 解除引用、转移引用、删除目标可作为一个跨表原子 MutationBatch。
- [ ] 引用删除安全与 Agent 写入、用户手动写入使用同一校验逻辑。
- [ ] 历史快照中的引用值保持当时的记录 ID，不因当前记录变化而改写。
