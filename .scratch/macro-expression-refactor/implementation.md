# 表达式宏实现与验收记录

日期：2026-10-26。分支：`codex/macro-expression-refactor`。

## 分工与状态

主代理负责运行时装配、统一求值调度、ST 生命周期、结果渲染、集成检查及文档。三个 Sol 6.1 Medium 子代理分别负责模型与持久化、SQLite／向量求值引擎、编辑界面及真实 ST 端到端验收。模型与引擎负责人交换负责范围做独立 Review；ST 并发生成归属难题由原 Astra Medium 核对宿主源码。

已实现完整 Query／SQL、命名语义源、有效索引全量评分与本批查询向量共享、隔离只读 SQLite 会话、生成时统一计算、对话宏空间持久化、预设宏、显式测试与最近结果。memoryRecall 专用服务、设置及注册入口已删除。实施后普通手动向量检索继续使用自己的状态和 Top K。

| json_each/json_tree 同名停用业务表被当虚拟表放行         | 根据完整业务表集合识别，真实 WASM 回归启停和名称覆盖                                 |

| 测试只发 abort，远端忽略取消会无限等待                   | 与真实计算一样用截止竞争释放调用，迟到结果独立清理                                   |

| 停止后其他插件提前截断拦截器链，下一次发送等待旧操作退出 | 提前本插件的拦截顺序，先确认取消并中断旧操作；真实 LittleWhiteBox 环境回归停止后重发 |

补充资源生命周期复核：超时原先只释放调用，永久不响应的 embedding 会保留 SQLite 会话。求值批次现已在取消时主动关闭，正常关闭、取消和迟到 finally 共用一次关闭 Promise；创建尚未返回时的取消也会在交付前清理。真实 WASM 与端口回归覆盖永久 pending、迟到响应不再执行 SQL、延迟创建和关闭错误原样暴露。

## 宿主限制

ST 的 STARTED 和 AFTER_COMMANDS 携带生成类型，AFTER_DATA 仅携带 dryRun，ENDED 是不带操作身份的全局 UI 事件。typed hooks 已排除 dry run、quiet 和 impersonate，无归属结束事件不会清除仍等待或尚未进入正常拦截器的批次。

正常操作已经进入提示词构建后，宿主无法区分并发 quiet 的完成事件与正常完成事件；同步宏回调也没有完整调用归属。MESSAGE_RECEIVED 虽可识别消息类型，但工具递归发生在该事件之后，不能用它替代整个操作的完成。Astra 确认现有接口无法证明任意异步交错的完全隔离；实现未加入推测性计数器，说明和需求已保留该限制。

本次新用户输入保存前就会被 ST 展开，无法使用其后才计算的本批结果；主要提示词、角色卡及世界书内容是本轮保障范围。

取消门禁依赖本插件的生成拦截器排在其他可能提前终止生成的拦截器之前。manifest 使用 `loading_order: -1000`；宿主未提供单独的拦截器优先级及带操作身份的完成回调。如果第三方扩展使用更低数值并提前中断，仍须调整加载顺序。端到端验收保留 LittleWhiteBox 启用，并检查实际拦截器排序。

## 验证

模型／迁移局部测试 188 项，引擎及原查询／手动检索回归、宏调度与集成测试在开发中分别执行。最终全量测试为 136 个文件、1464 项通过；TypeScript、ESLint、Prettier 与 `git diff --check` 均通过。停止后重发的新增测试读取实际 manifest 排序，并模拟下游插件提前中止。真实 ST 脚本见 [verify-expression-macros.mjs](../../docs/playwright-st-extension/verify-expression-macros.mjs)。

端到端验收使用独立测试角色与对话，embedding 凭据从本地环境读取，不写入代码或报告；主模型响应受控模拟，提示词生成和向量请求走真实 ST 与实际 embedding API。部署前备份原构建，结束恢复设置、清理测试角色与空间，并恢复原构建。

真实 ST 完整轮共 16 项检查通过，13 次真实 embedding 请求均 HTTP 200，页面和路由错误为零。覆盖正常 Chat Completion、Text Completion 与关键词世界书、Query／SQL 等价、空源 LEFT JOIN、界面编辑、最近结果只读、重生成／swipe／续写、独立预估与 quiet 零查询请求、跳过、停止后重发、迟到响应隔离、预设宏保存及非法 SQL 拒绝。Text Completion 本轮一次成功，未触发验收脚本的超时重测。

群聊验证采用真实 wrapper 事件包裹两次真实 Generate，证明批次复用，未建立完整群聊会话；工具递归由服务与事件桥测试覆盖。对话切换采用宿主允许的 STOP 后、HTTP 响应仍延迟期间 A→B→A，另有直接上下文变化的单元测试。完整轮主产物 SHA256 为 `815dc7e9ac5bfc5a3915568bbfdc54043a14ba49a917b0886e812f9a50461028`，Worker 为 `6cc0b734ac727e62b56cd39a1fe5fe6955ab9f631b5998e2ec738c2dc62df847`。

资源关闭修补后的最终主产物 SHA256 为 `e4edd319ce9e530a7e0c2a7625ba8d9219ff1931c4fcffaaee5eb666583957d3`，Worker 不变。该产物另完成合成向量的完整 ST 16 项复验，以及真实 API 停止专项 3 项检查，3 次请求均 HTTP 200、页面及会话关闭错误为零；旧生成与停止后的下一次发送均正常结束，Query／SQL 宏成功。完整真实轮与资源专项分别记录各自产物身份，没有将旧完整轮视为最终哈希的整轮重跑。结束后原构建五件文件按备份逐一校验恢复，测试角色、世界书、空间及对话清理成功，设置恢复。

性能测量使用真实 SQLite WASM、本地确定性向量，每条记录两个 1024 维组。1,000 条记录批次约 1.18 秒，10,000 条约 9.23 秒；后者尚未包含网络与最终文本渲染，生产 10 秒预算可能超时。Node 采样最高 RSS 分别约 168 与 463 MiB，不能替代浏览器峰值。阶段成本、内存口径与可复现脚本见 [性能记录](./performance.md)。
