# 设置界面移动端折叠与重排序

Status: ready-for-agent

## Problem Statement

设置 Tab 当前以固定顺序平铺 11 个分组（插件总开关、版本与运行状态、数据备份、云同步配置、同步状态、对话文件镜像、记忆宏与记忆视图、Agent 连接、Agent 提示词预设、清洗规则列表、危险操作），全部默认展开。在移动端（TauriTavern 全屏底部抽屉）形成极长的垂直滚动页，常用能力（记忆宏/视图、Agent 连接、Agent 提示词预设、清洗规则列表）被埋在中段，低频能力（版本与运行状态、云同步详情）占据首屏，用户每次调整记忆宏或切换 Agent 连接都需要长距离滚动，触控效率低。

## Solution

把设置 Tab 重构为可折叠的设置分组列表：每个一级分组可独立展开/收起，默认仅插件总开关展开其余折叠；按使用频率重排序常用分组至顶部，低频分组下沉，危险操作钉底；云同步配置与同步状态合并为单一分组以减少标题行；折叠态标题行保留一行摘要（当前宏名/视图数、连接数/选中连接、预设数/活动预设、清洗规则列表数/当前选择、云同步状态等），不展开即可扫视关键状态；展开/收起偏好持久化到本地存储，跨面板开关保留。桌面端沿用同一结构与交互。

## User Stories

1. 作为移动端用户，我想打开设置 Tab 时首屏即可扫完所有分组标题，以便快速定位目标设置而无需长滚动
2. 作为移动端用户，我想点击分组标题整行即可展开/收起该分组，以便单手操作且触控目标足够大
3. 作为移动端用户，我想看到分组标题右侧的 chevron 随展开状态切换，以便明确当前是展开还是收起
4. 作为移动端用户，我想默认只看到插件总开关展开、其余分组折叠，以便首屏信息密度聚焦在最关键的健康度开关
5. 作为用户，我想插件总开关始终钉在顶部且默认展开，以便随时确认插件启用状态与快速开关
6. 作为用户，我想危险操作始终钉在底部且默认折叠，以便不易误触且语义上属于兜底操作
7. 作为常用用户，我想记忆宏与记忆视图分组排在最顶部（总开关之下），以便最常用的注入配置一步直达
8. 作为常用用户，我想 Agent 连接分组排在第二位，以便快速切换表格填写 Agent 与查询 Agent 的 LLM 连接
9. 作为常用用户，我想 Agent 提示词预设分组排在第三位，以便快速切换或编辑当前活动预设
10. 作为常用用户，我想清洗规则列表分组排在第四位，以便快速查看当前对话选中的清洗规则与导入 ST 正则条目
11. 作为用户，我想数据备份分组排在清洗规则之后，以便导出/导入全库备份时可预期位置
12. 作为用户，我想对话文件镜像分组排在数据备份之后，以便开关镜像与是否包含修订历史的配置就近查找
13. 作为用户，我想云同步分组（已合并同步状态）排在对话文件镜像之后，以便 R2 四项配置与最近同步时间/失败提示/立即同步在同一折叠体内查看
14. 作为用户，我想版本与运行状态分组排在云同步之后、危险操作之前，以便低频的版本与运行状态信息不占用首屏
15. 作为用户，我想折叠态的记忆宏分组标题下看到一行摘要（如当前宏名与视图数量），以便不展开即可判断是否需要进入
16. 作为用户，我想折叠态的 Agent 连接分组看到摘要（如连接总数与表格填写/查询 Agent 的选中连接），以便不展开即可确认当前生效连接
17. 作为用户，我想折叠态的 Agent 提示词预设分组看到摘要（如预设总数与活动预设名），以便不展开即可确认当前生效预设
18. 作为用户，我想折叠态的清洗规则列表分组看到摘要（如列表总数与当前对话选中的列表名或未选择），以便不展开即可确认当前生效列表
19. 作为用户，我想折叠态的云同步分组看到摘要（如未配置/已开启/同步中/失败原因与最近同步时间），以便不展开即可判断同步健康度
20. 作为用户，我想折叠态的对话文件镜像分组看到摘要（如开关状态与镜像状态），以便不展开即可确认镜像是否生效
21. 作为用户，我想展开某分组后再次收起，关闭面板后重新打开仍保持上次的展开/收起状态，以便偏好被记住
22. 作为用户，我想首次安装或清空本地存储后，设置分组回到默认折叠状态（仅总开关展开），以便行为可预期
23. 作为键盘与读屏用户，我想分组标题按钮具有正确的展开状态语义，以便辅助技术可感知
24. 作为桌面端用户，我想在浮动面板中同样使用折叠与重排序后的设置布局，以便双端一致无需重新学习
25. 作为用户，我想展开的分组内原有控件与校验（R2 四输入、镜像开关、宏名与上限输入、记忆视图 CRUD、Agent 连接 CRUD 与测试连接、Agent 提示词预设 CRUD 与拖拽排序、清洗规则 CRUD 与导入、备份导出导入、危险操作的二次确认与置灰）行为完全不变，以便升级无感
26. 作为用户，我想云同步配置与同步状态在同一分组内上下排列（配置在上、状态与立即同步在下），以便配置与结果就近对照
27. 作为用户，我想在任意分组展开态下滚动面板时，其余折叠分组不发生布局跳动，以便阅读稳定

## Implementation Decisions

- **设置分组为折叠单元**：折叠以一级设置分组为单位，与现有视觉分组一一对应。不对分组内的单行开关或输入做二级折叠；记忆宏与记忆视图保持在同一分组内。
- **默认态**：仅插件总开关分组默认展开，其余分组默认折叠。危险操作分组同样默认折叠但语义上钉底。
- **重排序后顺序（自上而下）**：插件总开关（钉顶、永不折叠）> 记忆宏与记忆视图 > Agent 连接 > Agent 提示词预设 > 清洗规则列表 > 数据备份 > 对话文件镜像 > 云同步（含同步状态）> 版本与运行状态 > 危险操作（钉底）。
- **云同步分组合并**：将原本分离的云同步配置分组与同步状态分组合并为单一可折叠分组，内部自上而下为 R2 四项输入、提示文案、同步状态行、最近同步行、失败提示行、立即同步按钮，避免移动端出现两个连续的云同步标题。
- **折叠头摘要**：折叠态标题行下方保留一行 12px 副标题摘要，派生自已有状态与设置：记忆宏显示当前宏名与视图数；Agent 连接显示总数与两个 Agent 的选中连接（跟随 ST 当前连接时显示对应文案）；Agent 提示词预设显示总数与活动预设名；清洗规则列表显示总数与当前对话选中列表名或未选择；云同步显示是否已配置、同步中、失败原因与最近同步时间；对话文件镜像显示开关与镜像状态；无值时显示未配置或默认值文案。摘要为只读派生，不引入新存储。
- **交互形态**：分组标题栏整行可点击展开/收起，右侧 chevron 图标随状态切换（展开向上、收起向下），复用表格卡片已有的展开按钮语义。标题按钮暴露展开状态语义，触控目标不小于现有开关与按钮的可用性契约，动效尊重减少动效偏好。
- **持久化**：展开/收起偏好持久化到本地存储（与面板几何同机制），键为稳定分组标识集合（如记忆宏、Agent 连接、Agent 提示词预设、清洗规则、备份、镜像、云同步、版本、危险操作），插件总开关不参与折叠持久化。首次加载或存储缺失时回退到默认态；用户每次切换后覆盖存储。不改动插件设置形状与备份/云同步信封，折叠偏好为纯展示状态，不随备份导入导出或云同步传播。
- **架构**：折叠状态由纯逻辑的分组折叠模型承载（是否为展开、切换分组），设置 Tab 仅做状态到界面的投影与事件接线。插件设置读写与合并逻辑保持不变。
- **词汇**：引入应用层术语设置分组，指代设置 Tab 内可独立折叠的一级分组，默认除插件总开关外折叠；在 st-extension 上下文词汇表中记录，不重复定义领域层词汇。
- **可逆性**：本调整为纯展示层重排与折叠，不改动存储结构、同步协议或备份格式，回退仅需恢复渲染顺序与移除折叠容器。

## Testing Decisions

- **好测试的判定**：只测外部可见行为（分组标题与顺序、展开/收起后内容的可见性、摘要文案、持久化后重载的初始状态、无障碍属性），不测实现细节（不测内部 CSS 类名以外的样式、不测 IndexedDB 内部、不测 ST DOM）。
- **测试 seam**：沿用项目唯一的纯逻辑层与面板冒烟层。新增或复用一个纯逻辑分组折叠模型（输入为分组标识集合，输出为是否展开与切换后集合），以单元测试覆盖默认态、切换、持久化键的稳定映射与回退；设置 Tab 的渲染通过现有面板冒烟测试（服务端渲染为字符串断言关键标记与顺序）覆盖折叠头、顺序与无障碍属性。理想 seam 数量为一，纯逻辑模型与面板投影共用同一契约。
- **先验参照**：表格卡片的展开/收起已在面板中有现成模式与测试；记忆视图、清洗规则与 Agent 连接的纯逻辑模型与组件冒烟测试为本分组折叠的参照；面板冒烟测试中对设置分组标题与同步状态的断言为回归锚点。异步加载与真机验收脚本覆盖的表格列表完整渲染不在本范围内。
- **持久化测试**：以可注入的存储端口或 fake 存储覆盖写入与读取、损坏或缺失存储时的回退到默认、分组标识未知时的丢弃。
- **手动验收（不进 CI）**：移动端抽屉内首屏可扫完标题、整行点击与 chevron 同步、摘要在折叠态可见、重排序后常用分组一步直达、云同步配置与状态在同一分组内可见、桌面浮动面板同布局。

## Out of Scope

- 改动插件设置形状、备份文件信封或云同步文件与索引格式
- 为设置分组增加全部展开或全部折叠快捷按钮
- 改动表格、记录、任务、问答、日志等其他 Tab 的布局与交互
- 引入新的主题、色板令牌或浅色模式
- 为折叠功能新增独立的架构决策记录（本调整可逆且无惊讶权衡）
- 将折叠偏好纳入备份或云同步的跨设备传播

## Further Notes

- 插件总开关钉顶且默认展开是健康度锚点，便于排障时快速确认启用状态；危险操作钉底符合安全预期。
- 云同步两组合一后，R2 未配置时的同步状态提示与立即同步按钮的置灰逻辑保持不变。
- 摘要文案复用已有派生（同步状态摘要、镜像状态摘要等），避免新增与领域词汇冲突的展示逻辑。
- 后续若需按角色区分常用顺序，可在保留当前重排序的基础上通过用户偏好或使用频率再演进，无需改动存储结构。
