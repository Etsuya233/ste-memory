# UI 原型 · 墨灰主题（视觉规格）

状态：**视觉规格原型，不进构建**。设计系统已在 `feat/redesign` 落地，规则与文件地图见 [`docs/ui/design-system.md`](../../docs/ui/design-system.md)；本原型作为视觉参照保留。

## 怎么看

**本机**：直接打开 `http://localhost:8788/prototype.html`（本地服务已在跑），或双击文件用浏览器打开。

**iPhone**：连同一 Wi-Fi，打开 `http://192.168.1.84:8788/prototype.html`。

## 原型里可以做什么

- 左上角 **☰** 打开侧边抽屉，切 6 个区（表格 / 记录 / 任务 / 问答 / 日志 / 设置）；
- 右下角 **滑块按钮** 打开「外观」面板：**主题（深/浅）× 强调色（系统蓝/中性白/靛蓝/青绿）× 字体（系统/衬线）× 字号（紧凑/标准/大）**，四个旋钮全部即时生效；
- 设置页里的「外观」分组是将来真实设置项的预览，和浮层面板同源可点；
- 记录页底部有「1 条记录已修改」的悬浮保存条（脏状态的形态）。

## 主题系统定义（本版原型即规范）

风格名：**墨灰** —— zinc 中性阶 + 语义令牌 + 可换强调色，深/浅双主题。

**三层令牌**

```
色阶层（不直接使用）       语义层（组件唯一入口）          旋钮层（用户切换）
zinc 50–950        →    --stm-bg / --stm-surface…   ←  data-theme  （深色/浅色）
blue/indigo/teal   →    --stm-accent / -text / -fg ←  data-accent（强调色）
系统/衬线字体栈     →    --stm-font                  ←  data-font  （字体）
12/13/15/17px 基准 →    --stm-fs-*                  ←  data-size  （字号缩放）
```

**组件层硬规则**

1. 只引用语义令牌，不出现十六进制字面量；
2. 一套组件、五种按钮变体（primary / secondary / outline / ghost / danger）；
3. 圆角两档（控件 10 / 卡片 14）；控件高度 44px（触控契约）；
4. 字号缩放只作用于文字（`calc(Npx * var(--stm-font-scale))`），不缩控件；
5. 分组用“标签 + 卡片 + 细线分隔”，不给每行画框、不用虚线。

**落进插件时**：四个 `data-*` 属性挂到 `#stm-panel` 根元素（ST 顶栏按钮在面板外，维持现有中性图标样式）；设置存 `PluginSettings.appearance`，在设置 Tab 新增「外观」分组；`tokens.css` 重写为上面这套语义令牌。
