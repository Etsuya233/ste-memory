# 面板安全区：四边可调留空

Status: ready-for-agent

## Problem Statement

TauriTavern（Tauri v2 打包的 SillyTavern 客户端，iPhone 17 实测）的 WebView 不向页面报告系统安全区——`env(safe-area-inset-*)` 恒为 0（未配置 viewport-fit=cover 的 WKWebView 行为）。插件在移动端（<1001px）渲染为 `top: 0` 锚定 + `100dvh` 的全屏底部抽屉，面板头部直接顶进灵动岛/状态栏区域，底部手势条区域也无保护。ST 内部 UI 自带安全区优化，第三方插件面板普遍中招（这是宿主级问题，不止本插件）。用户需要一种方式让面板自己避开屏幕四边的遮挡区。

## Solution

插件提供**面板安全区**：移动端布局下，面板整体相对视口四边（上/下/左/右）按用户配置内缩，露出遮挡区并让内容避开。配置为纯手动（不检测宿主自动填值）：默认四边全 0（行为与现状完全一致，装上即无感），用户在设置 Tab 的新分组「面板安全区」中用四个数字输入（px，0～120，步进 1）调整，也可从预设一键填充（iPhone 灵动岛 59/34/0/0、iPhone 刘海屏 47/34/0/0、清空）。数值存 localStorage（设备相关偏好，与面板几何同机制），不进插件设置、不随备份/云同步传播。桌面浮动窗口（≥1001px）不消费这些值，行为不变。

## User Stories

1. 作为 TauriTavern（iPhone 17）用户，我想把面板上边内缩至少 59px，以便面板头部/标题/收起按钮不被灵动岛遮挡
2. 作为 TauriTavern 用户，我想把面板下边内缩至少 34px，以便底部 Tab 不顶进 Home Indicator 手势条区域
3. 作为横屏使用用户，我想分别调整左右内缩（灵动岛/刘海机型横屏时圆角与挖孔可占两侧约 44px），以便横屏时内容不被两侧圆角切掉
4. 作为用户，我想在设置 Tab 看到「面板安全区」分组，以便找到四边调整入口
5. 作为用户，我想用四个数字输入分别调整上/下/左/右内缩（px，步进 1、范围 0～120），以便按自己设备的实际遮挡精确配置
6. 作为用户，我想输入超出范围或非整数时被钳制/取整到合法值，以便配置不可能进入非法状态
7. 作为用户，我想一键填入「iPhone 灵动岛」预设（59/34/0/0），以便免去手工输数
8. 作为用户，我想一键填入「iPhone 刘海屏」预设（47/34/0/0），以便旧机型也能快速配置
9. 作为用户，我想「清空」预设把四边归零，以便恢复默认全屏行为
10. 作为用户，我想调整后立即生效、无需重启或重开面板，以便所见即所得
11. 作为用户，我想关闭面板再打开后数值保持，以便偏好被记住
12. 作为首次安装或清空本地存储的用户，我想四边默认全 0，以便装上插件行为与之前完全一致、无意外变化
13. 作为用户，我想面板内缩后关闭动画仍正常（整体推出视口），以便收起交互不受影响
14. 作为桌面端用户，我想桌面浮动窗口（≥1001px）不读取这些值，以便窗口几何/拖拽/缩放行为完全不变
15. 作为移动浏览器（非 Tauri）用户，我想面板内部原有的 env(safe-area-inset-bottom) 内容留白保持不变，以便现有浏览器端表现无回归
16. 作为用户，我想设置 Tab 的「面板安全区」分组默认折叠，折叠态标题下看到一行摘要（四边当前值或"未调整"），以便不展开即可扫视
17. 作为键盘与读屏用户，我想四个数字输入有可读的标签（上/下/左/右），以便辅助技术可操作
18. 作为在多个设备间使用同步/备份的用户，我想安全区数值是本机偏好，以便每台设备按自己的屏幕独立配置、互不污染

## Implementation Decisions

1. **新纯逻辑模型承载安全区**：四边形状 {top, bottom, left, right}（px），默认全 0。解析/校验遵循面板几何的先例风格：非法存储（非数字、NaN/Infinity、越界、形状损坏）整体回退默认，不弹错。数值域 0～120 整数；UI 输入提交时钳制到域内并取整。
2. **持久化 = localStorage**：键 `steMemory.panelSafeArea`（与面板几何/设置折叠同前缀）。走既有 safeLocalStorage 端口（隐私模式吞异常）。不进 PluginSettings、不参与备份导出导入与云同步——安全区是设备相关显示偏好，语义与面板几何一致。
3. **预设为一键填充，不引入新存储结构**：预设表两个命名方案 + 清空（全 0）。点按仅把四边数值写入生效配置，无独立"已选预设"状态、无预设持久化。
4. **设置分组**：设置 Tab 新增「面板安全区」分组，参与折叠（默认折叠，与其余分组一致），折叠摘要显示四边当前值（全 0 时显示"未调整"）。分组位置在版本与运行状态之后、危险操作之前（低频显示偏好）。
5. **UI 接线复用面板宿主**：四个 `<input type="number">`（min 0 / max 120 / step 1，显式 label）+ 三个预设按钮，渲染与折叠逻辑走现有设置分组机制，读写经同一 localStorage 端口。
6. **CSS 消费方式**：面板宿主把四边值落到面板元素上的四个新 CSS 变量（与窗口几何变量同模式），移动媒体查询（<1001px，与现有抽屉断点同源）内消费为整体内缩；桌面媒体查询不消费（惰性，与窗口几何一致）。
7. **避开移动端 bottom 锚定陷阱**：面板当前用 `top: 0` 锚定是因为 ST 给 html 加 transform 使 fixed 包含块塌缩（样式注释中已记录的真机踩坑），不能改用 `bottom: 0` 表达底部内缩——底部内缩必须以高度计算或等效方式表达，保持 top 锚定与关闭态 translateY(100%) 语义不变。
8. **无宿主特判**：不检测 TauriTavern（`window.__TAURITAVERN__`）或 iOS 自动填值。灵动岛高度会随系统状态（通话、热点）动态变化，自动填"常态值"不可靠；预设 + 手动让用户对自己设备负责。
9. **与内部 env 留白并存**：tabbar/body 现有的 env(safe-area-inset-bottom) 内容留白不动。手动内缩作用于面板边框，两个维度互不干扰（Tauri 宿主中 env=0，由手动值兜底；浏览器中两者可能叠加底部留白，属可接受且用户可见）。
10. **生效时机**：数值为静态用户配置，面板挂载时读取 + 调整时写回即可，不需要监听系统 inset 变化、旋转或灵动岛展开。

## Testing Decisions

- **好测试的判定**：只测外部可见行为——默认值、非法存储回退、数值域校验（越界/非整数被钳制取整）、预设填充结果、localStorage 读写的往返与键稳定性、设置分组中控件与预设按钮的存在性；不测 CSS 消费细节、不测真实 IndexedDB/ST DOM。
- **seam（唯一新 seam）**：纯逻辑的安全区模型（形状/默认/校验/预设/存储端口），单元测试全覆盖；设置分组与控件的渲染断言复用面板冒烟层。理想 seam 数量为一，模型与面板投影共用同一契约。
- **被测模块**：安全区模型（单元测试）+ 面板冒烟（分组标题、四个输入、三个预设按钮、无障碍标签、折叠摘要）。
- **先验参照**：面板几何的解析/回退与存储端口测试（`panel-window.test.ts`）、设置分组折叠的加载/保存/切换测试、面板冒烟层对设置分组标题的断言（`panel-shell.test.tsx`）、设置合并的校验风格（`plugin-settings.test.ts`）。
- **手动验收（不进 CI）**：TauriTavern + iPhone 真机——顶部内缩后头部避开灵动岛、底部避让手势条、横屏左右内缩、关闭动画仍完整推出、桌面浮动窗口行为无回归、普通移动浏览器（env 生效）底部表现无回归。

## Out of Scope

- 检测宿主自动填值 / TauriTavern 特判（预设 + 手动已覆盖）
- 合并或移除面板内部的 env(safe-area-inset-bottom) 内容留白（并存，见决策 9）
- 跟随系统 inset 动态变化（灵动岛展开、旋转时自动换边）
- 桌面浮动窗口的几何改动（有独立 24px 视口钳制）
- 多套命名配置/设备档案（预设即上限）
- 设置随备份/云同步传播（本机偏好）
- 负值内缩、非整数精度、120px 以上取值

## Further Notes

- 词汇：**面板安全区**已写入 st-extension 上下文词汇表（区别于系统安全区 = env() 本体）；决策 7 的"内缩实现须避开 bottom 锚定陷阱"是唯一需要实现者警惕的历史坑。
- 预设数值来源为 iOS 安全区常态值（灵动岛机型竖屏 top 59 / bottom 34，刘海机型 top 47 / bottom 34，横屏左右 44）；实现时如引用需注明出处。
- 数值单位是 CSS px，与设备像素比无关，用户按屏幕实际观感调整。
