# ST Extension

该上下文描述 SillyTavern UI Extension（`apps/st-extension`）：一个自包含的浏览器扩展，与 apps（api/web）互不依赖，只与它们共享 core 的领域词汇。领域词汇在 `core/CONTEXT.md` 中定义，此处不重复。

## Language

**同步楼层**：
SillyTavern 当前对话中消息的数组下标，插件用作消息引用的适配器层身份（来源 ID）。同步楼层会因删除、重生成或 swipe 而漂移，不代表稳定的消息身份。消息全文不落库，楼层范围随时从 ST 对话实时读取（填表日志中的 Prompt 快照是唯一例外，见运行记录）；哪些楼层已填表由填表任务的楼层进度台账记录。
_Avoid_: 消息 ID、证据身份、楼层号（领域层）

**记忆宏**：
由插件注册、用户自行放入提示词预设（角色卡、系统提示、作者注释等）的宏，在生成时展开为当前记忆表格的上下文文本。宏名由用户配置，不写死；展开内容是插件预计算好的快照。
_Avoid_: 自动注入、注入文本、预设字符串

**Agent 提示词预设**：
为表格填写 Agent 准备的命名提示词模板档案，由可独立开关与排序的片段组成；预设文本中的占位符在任务提交时展开为当前对话与记忆空间的信息。全局有一个活动预设决定当前生效的提示词。
_Avoid_: Prompt 预设、System Prompt 覆盖、破限词库

**片段**：
Agent 提示词预设内一个命名的提示词文本单元，可单独开关，并决定其在最终提示词中的顺序。
_Avoid_: Prompt 条目、段落

**系统默认预设**：
插件内置的只读 Agent 提示词预设，内容等价于未配置任何预设时的系统提示词，作为回退锚点。
_Avoid_: 默认配置、内置模板

**活动预设**：
当前生效的 Agent 提示词预设，切换后影响后续填表任务的提示词。
_Avoid_: 当前预设、选中预设

**记忆空间绑定**：
对话与记忆空间的对应关系，随对话文件持久化（小元数据），保证对话重命名后绑定不丢失。
_Avoid_: 数据库主键、空间 ID 存储

**对话文件镜像**：
随聊天文件（chat_metadata.steMemoryMirror）走的记忆快照：结构 + 记录 + 修订历史 + 证据（与备份单元同构）。镜像只作恢复源——本地空间缺失时恢复，绝不覆盖本地；双向 LWW（本地较新才写回文件）。独立键，不动绑定键。
_Avoid_: 备份、云同步、聊天文件内嵌数据

**云同步**：
插件把 Dexie 记忆数据同步到 Cloudflare R2（S3 兼容）的机制：本地优先（本地有库则用本地，仅空库启动拉取全量）、数据变更防抖周期推送、冲突较新版本胜出（LWW）。R2 四项配置齐全即自动启用；失败按退避自动重试，最近同步时间与失败提示在设置面板可见。
_Avoid_: 备份、云端存储

**世界书（worldbook）**：
SillyTavern 的 World Info（lorebook）。插件**委托** ST 的扫描（getContext 的 getWorldInfoPrompt，dry run）获取与给定文本匹配的条目，自身不实现匹配规则——生效书本选择（全局/角色/对话书、群聊策略）、关键词与正则、预算截断等全部由 ST 处理。
_Avoid_: 世界信息、世界观书、lorebook（英文专名除外）

**世界书占位符（{{worldbook}}）**：
Agent 提示词预设占位符，任务提交时把任务范围剧情文本（名字：内容逐行拼接）作为单条消息交给 ST 世界书扫描，展开为激活条目的原文内容；无世界书、无匹配、旧版 ST 或扫描失败时展开为空串且不阻断任务。
_Avoid_: 世界书宏、lorebook 宏

**通用日志**：
插件本地持久化的审计日志存储，按类型与键组织、可过滤，供事后复盘与排障；填表日志是其中一种类型。日志是本地审计数据，不参与云同步与备份。
_Avoid_: 日志文件、console 输出

**填表日志**：
通用日志中类型为填表运行记录的集合，覆盖一次填表任务的全部消息块，记录每轮 LLM 请求、工具调用与模型输出，供事后复盘 Agent 的填写过程。
_Avoid_: 运行历史、聊天记录

**运行记录**：
一个消息块对应的一次表格填写 Agent 运行的完整记录：该块的系统提示词快照（含预设片段展开与世界书内容）、逐轮 LLM 请求消息、工具调用（参数/结果/错误）与模型输出（含用量与停止原因）。
_Avoid_: 日志条目、块日志

**工具调用**：
填写 Agent 在一次运行中对工具的调用及其参数与结果（查询记录、变更、提案预览、放弃变更、提交提案）；工具调用是运行记录的内容单元。
_Avoid_: 方法调用、函数调用
