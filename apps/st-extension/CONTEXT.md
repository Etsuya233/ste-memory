# ST Extension

该上下文描述 SillyTavern UI Extension（`apps/st-extension`）：一个自包含的浏览器扩展，与 apps（api/web）互不依赖，只与它们共享 core 的领域词汇。领域词汇在 `core/CONTEXT.md` 中定义，此处不重复。

## Language

**同步楼层**：
SillyTavern 当前对话中消息的数组下标，插件用作消息引用的适配器层身份（来源 ID）。同步楼层会因删除、重生成或 swipe 而漂移，不代表稳定的消息身份。消息全文不落库，楼层范围随时从 ST 对话实时读取；哪些楼层已填表由填表任务的楼层进度台账记录。
_Avoid_: 消息 ID、证据身份、楼层号（领域层）

**记忆宏**：
由插件注册、用户自行放入提示词预设（角色卡、系统提示、作者注释等）的宏，在生成时展开为当前记忆表格的上下文文本。宏名由用户配置，不写死；展开内容是插件预计算好的快照。
_Avoid_: 自动注入、注入文本、预设字符串

**记忆空间绑定**：
对话与记忆空间的对应关系，随对话文件持久化（小元数据），保证对话重命名后绑定不丢失。
_Avoid_: 数据库主键、空间 ID 存储

**对话文件镜像**：
随聊天文件（chat_metadata.steMemoryMirror）走的记忆快照：结构 + 记录 + 修订历史 + 证据（与备份单元同构）。镜像只作恢复源——本地空间缺失时恢复，绝不覆盖本地；双向 LWW（本地较新才写回文件）。独立键，不动绑定键。
_Avoid_: 备份、云同步、聊天文件内嵌数据

**云同步**：
插件把 Dexie 记忆数据同步到 Cloudflare R2（S3 兼容）的机制：本地优先（本地有库则用本地，仅空库启动拉取全量）、数据变更防抖周期推送、冲突较新版本胜出（LWW）。R2 四项配置齐全即自动启用；失败按退避自动重试，最近同步时间与失败提示在设置面板可见。
_Avoid_: 备份、云端存储
