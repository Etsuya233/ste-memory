# 填表日志快照完整 Prompt（打破"消息全文不落库"）

填表日志需要记录每轮 LLM 请求、工具调用与模型输出，供事后复盘 Agent 的填写过程；为此日志快照**完整 Prompt**（含对话消息全文、世界书展开与预设展开后的系统提示词），作为 ADR 0003"消息全文不落库"原则的受控例外。

ADR 0003 的"不落库"针对记忆数据：ST 本身是消息源，消息本体不承担记忆身份职责。填表日志是**审计数据**不是记忆数据——它落库的是运行快照（"当时模型看到了什么"），不参与记忆空间的任何查询与同步。选择快照而非楼层引用的原因：同步楼层会因删除、重生成、swipe 漂移，引用在事后无法还原当时的 Prompt；快照则保证复盘时所见即当时所发。日志纯本地存储，不参与云同步、备份文件与对话文件镜像，空间删除时级联清理。

不选方案：只存楼层引用（漂移失真，事后不可复盘）；只存提示词模板不存展开结果（预设与世界书是提交时快照，事后不可还原）；日志进云同步或备份（污染记忆数据的同步语义，扩大对话原文的暴露面）。
