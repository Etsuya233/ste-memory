# Apps

该上下文描述应用层：`apps/api` 与 `apps/web` 是一对，web 前端通过 HTTP 与 api 对话，共享同一套应用层词汇。领域词汇在 `core/CONTEXT.md` 中定义，此处不重复。

## Language

**清洗规则**：
记忆空间内按顺序执行的正则规则，作用于导入消息的内容，以「保留」或「去掉」模式改写消息内容，影响消息展示与填表任务输入；存储的原始消息内容不被改写。
_Avoid_: 正则脚本、过滤规则、文本替换

**交互式填写**：
用户在边栏聊天中与表格填写 Agent 对话，由 Agent 提出记忆记录变更并在提交前征得用户明确同意的填写方式；变更经提案管线自动落库，与后台填表任务相对。
_Avoid_: Agent 对话、聊天写库、Agent 直写
