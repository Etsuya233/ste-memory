# 界面统一优化方案

以记录页当前版本为后续页面的设计与实现基线，优先服务移动端，同时适配桌面窄面板。目标是整洁、紧凑、操作自然：通过布局、层级和状态解释功能，把必要操作放在稳定位置，减少重复标题和常驻说明。

本方案覆盖表格、设置、检索、任务、问答和日志。记录页、表格管理与任务页已应用统一组件和视觉规则，其余页面按下文顺序迁移。记录页基线来自 `dd0d6cb`，触屏反馈规则随 `cc254d4` 更新，既有实现说明见 [移动端 UI](mobile-design.md)。

## 页面结构与职责

普通页面由 `PageLayout` 统一管理顶栏、内容滚动区和底栏。页面负责业务内容及操作，容器负责安全区、实际栏高、内容避让和玻璃模式覆盖。页面 CSS 不再计算 `safe-area-inset-*`，不使用负边距抵消容器 padding，也不通过固定 60px 补偿多行顶栏。

顶栏与底栏按内容测量高度，60px 是栏的最小高度。内容短时底栏仍靠近容器底部，内容长时最后一项能够完整滚到栏上方。普通页面沿用一个主滚动区。表格管理统一采用列表进入详情的单列流程，移动端和桌面保持一致，不再保留左右分栏或独立内部滚动。

| 现有组件 | 负责内容 | 使用边界 |
| --- | --- | --- |
| `PageLayout` | 栏位、滚动、尺寸测量、安全区和内容避让 | 表格管理及其他普通页面使用 scroll；contained 仅用于确有独立内部布局需求的场景 |
| `PageChrome` | 子页面向所属容器声明顶栏、底栏或默认顶栏右侧操作 | 当前状态只能有一个顶栏提供者、一个底栏提供者；切页时明确卸载旧声明 |
| `PanelBar` | leading、居中 title、可选 subtitle、trailing 和 extension | 搜索或筛选可放 extension；随内容滚动的工具区留在正文 |
| `PanelBarAction` | 标准图标按钮、名称、强调色或危险色 | 保留原生提交、禁用、ref 和事件能力 |
| `PanelBottomBar` | 主操作胶囊与独立快捷操作 | 只放需要持续可达的操作或状态；没有此需求就不渲染 |
| `Tabs` | 受控页面切换、胶囊样式和键盘导航 | 传入 value、options、onChange；每项 panelId 对应页面区域，支持方向键与 Home/End |
| `Disclosure` | 原生 details 的标题、图标、状态、箭头和展开内容 | 用于历史、索引、诊断等次要信息，不包住主要操作路径 |

Shell 已提供 PageLayout，普通子页面通过 PageChrome 调整栏内容即可。独立工作台再按需建立内部 PageLayout。不要让多个子组件竞争覆盖整条顶栏；页面层汇总操作，子组件通过 props 或回调提供状态和动作。列表页可通过 `PageChrome.headerTrailing` 将操作插入默认顶栏的 `PageHeaderActions` 位置，与关闭按钮共享胶囊；仅有一个页面扩展提供者。详情仍替换完整顶栏。当前没有优先级叠加或操作注册表。

Portal 内容会脱离原 DOM 祖先，因此不能依赖正文的 `hidden` 隐藏顶底栏。详情和编辑页要明确停止渲染列表底栏。顶栏保存按钮离开表单 DOM 后，通过 `form={formId}` 关联原生表单，继续走统一提交与校验流程。

## 顶底栏与操作安排

顶栏左侧负责导航：一级页面打开导航，详情返回，编辑取消。中间保留一个标题，副标题只承载有助于识别当前上下文的信息。右侧放当前页面的主要操作，同组按钮共用胶囊，单按钮使用圆形容器。移动端每侧优先控制在两个快捷操作以内，更多动作先评估低频菜单或正文入口。

优先使用含义明确的图标，所有图标按钮都必须有 `label`，生成无障碍名称和悬停提示。陌生或容易混淆的动作保留短文字。选中、禁用、处理中和危险状态必须可识别；删除使用危险色并保留确认，创建状态不显示删除。

底栏适合分页、发送、持续执行等需要稳定位置的操作。记录页的“上一页、页码、下一页”共用胶囊，新建按钮独立放在旁边。同一操作不在顶栏、正文和底栏重复出现。批量保存、放弃等动作只在对应模式出现，执行中阻止重复提交和冲突操作。

列表进入详情前保存滚动位置，返回恢复；更换页码或内容范围时回到合理的起始位置。恢复应在栏布局完成后执行，避免浏览器按旧滚动范围截短位置。导航打开后约束焦点，关闭时返回触发入口；表单未保存修改继续使用现有离开保护。

## 列表与展开内容

列表采用备忘录式分组：同类条目共享一个圆角 surface，行间使用从文本起点开始的内缩分隔线。行内统一左右留白，避免每条再套独立卡片或阴影。记录摘要以约 80px 为默认行高参考，其他列表按实际内容调整，并保持操作区域至少 44px。

普通条目采用主次两行：主行显示名称，次行显示简短摘要或关键状态。长文本在列表内省略，完整内容进入详情查看。默认摘要不重复所有行都相同的字段标签。右侧只放必要状态、进入提示或明确的独立操作；不为视觉一致性添加没有业务含义的开关。整行导航与右侧独立按钮同时存在时，应分离点击目标，避免嵌套 button。

分类标签数量少时直接展示，较多时横向滚动，标签文字保持完整。记录页工具区的基线是“表标签整行横滑，下方计数或搜索输入靠左，图标切换和搜索靠右”。其他页面按信息量沿用此关系，避免为两个小按钮空出一整行。

历史、索引和高级配置使用统一 Disclosure：左侧图标与标题，右侧数量或状态及箭头，展开后使用同套内容留白。原生 summary 保留键盘开合。主要内容和关键错误保持可见，次要诊断默认收起；不连续嵌套多层展开区。

圆角分组列表共用 `stm-grouped-list`，统一 1px 边框、背景和圆角，记录摘要、表格和字段列表均接入；业务样式只管理行内布局与分隔线。无需增加仅转发 children 和 className 的 React 包装。

## 视觉 Token 与玻璃材质

字号、字重、颜色、间距和圆角都引用 `tokens.css`。模块可以定义业务布局，公共视觉值不再各自硬编码。派生字号和颜色需要在面板作用域重新计算，以响应深浅主题与外观字号设置。

| 类别 | 统一基线 | 使用建议 |
| --- | --- | --- |
| 字号 | fs-xs 12、fs-sm 13、fs-md 15、fs-lg 17px，统一乘 font-scale | 状态、摘要、正文、页面标题依次使用对应等级 |
| 字重 | regular 400、medium 500、semibold 600 | 正文常规，条目标题中等，页面标题加粗 |
| 行高 | tight 1.3、normal 1.5、relaxed 1.65 | 单行标题、短文、长文分别使用 |
| 间距 | space-1 至 6 为 4、8、12、16、20、24px | 优先从现有等级选择 |
| 页面与行 | page-padding 16px、row-padding-y 12px | 页面留白交给容器；分组行使用统一文本起点 |
| 控件与圆角 | control-h 44px、radius 14px、radius-card 引用 radius | 按钮触控高度保持；胶囊使用全圆角 |
| 颜色 | bg、surface、surface-2、border；fg、fg-2、fg-3 | 背景层级与主次文字分开表达 |
| 状态 | accent、success、warning、danger | 强调色用于选中和操作；危险色专用于危险动作 |
| 栏材质 | bar-* 与 glass-fade 48px | 顶底栏共用，页面不单独修改模糊策略 |

Liquid Glass 开关属于本机外观设置。当前跨平台基线为：顶栏背景向下渐隐、底栏背景向上渐隐，背景使用主题渐变色；圆形和胶囊按钮保留真实 backdrop blur。大面积背景不再叠加渐变模糊遮罩，不增加平台判断。不要把 Chromium 已出现硬边的 backdrop-filter 与渐变 mask 组合重新带回公共栏。

插件范围统一清除文字阴影，保持独立于 SillyTavern 的全局 text-shadow。深浅主题都需检验边界和文字对比，不能靠新增阴影补救可读性。没有视觉收益的动效不增加，新增必要动效需尊重 reduced-motion。

## 触屏与指针反馈

所有 Hover 样式都限定在 `@media (hover: hover) and (pointer: fine)` 内，按输入能力判断，不使用设备名或 User Agent。触屏设备不呈现 Hover；选中、焦点、禁用和错误状态继续独立表达。支持悬停的鼠标设备保留 Hover。

标准图标操作复用 PanelBarAction：按住任一按钮时，所属胶囊 Panel 连同内部所有按钮整体放大到 1.035，持续按住保持放大，松开以 120ms 恢复。左右操作组分别响应，整条顶栏不参与缩放，按钮自身不叠加缩放；pointerup、pointercancel、pointerleave 和丢失指针捕获时清除按压状态。Panel 保持原来的布局尺寸，不因视觉缩放引发布局跳动。原生 `:active` 的缩放仅用于键盘焦点操作，避免移动浏览器延迟清除该状态而拖长按压反馈。禁用按钮不响应按压，页面不再复制事件实现。

普通按钮、列表行和展开标题保留 Active 的颜色反馈。混合选择器中的 focus-visible 必须单独保留，不能随 Hover 一起被媒体条件屏蔽。开启减少动态效果时关闭图标缩放与过渡，仍显示按下颜色。验收需覆盖触摸按住、松开、取消，鼠标悬停和键盘空格操作；`pointer-check.cjs` 提供这组交互检查。

## 其他页面的改造顺序

以下安排按公共组件的复用价值排序，每轮完成一个可体验的页面流程。任务页已统一类型切换、分组列表、Disclosure 与活动/分页底栏，保留隐藏页面草稿并暂停其轮询和栏位声明。表格管理已完成单列改造：分组表列表进入字段详情，表格信息、显示策略、向量索引由配置区进入；表与字段编辑统一使用顶栏保存、取消及删除，保留原有表单校验并接入未保存修改保护。

| 顺序 | 页面 | 重点改造 | 保留的业务能力 |
| --- | --- | --- | --- |
| 1 | 表格与字段 | 对齐分组列表、图标操作和编辑顶栏；统一字段、显示策略、向量配置的展开层级 | 启停、字段编辑与删除、字段依赖、显示策略和向量配置；所有尺寸统一单列导航 |
| 2 | 设置 | 分类行统一主次层级；分类详情共用返回顶栏；连接和预设编辑统一表单动作 | 配置持久化、连接测试、预设编辑、备份恢复及其确认 |
| 3 | 检索 | 查询输入突出，范围与筛选紧凑排列，结果采用分组摘要；诊断使用 Disclosure | 搜索、取消、结果定位、索引状态与错误反馈 |
| 4 | 任务 | 类型切换与状态筛选集中，任务摘要紧凑；批量动作按选择状态出现 | 实时状态、取消、重试、失败原因与任务详情 |
| 5 | 问答 | 对话内容与输入区分层，输入和发送使用容器底部区域；调试信息收起 | 流式输出、取消、消息记录和错误处理 |
| 6 | 日志 | 级别筛选、搜索与数量集中；日志条目分组，长内容按需展开 | 时间、级别、上下文、复制与清理 |

迁移时先明确用户在该页最常做的动作，再安排信息层级。不要把记录页的 80px 行高、分页或左右按钮数量机械套给所有页面。问答当前保留单行输入，输入区需要单独验证软键盘；若后续支持多行，需验证输入增长与栏高测量；任务和日志需要验证更新期间的滚动稳定性。

## 每轮实施流程

先记录该页面的主要路径、低频配置、危险操作和现有数据契约，保留重要的 data-action 选择器与离开保护。随后接入统一容器和顶底栏，再整理列表、表单、展开区与工具区，最后清理重复 CSS 和硬编码 Token。

只修改这一轮页面及必要的公共组件。公共组件发生变化时，回归记录页和已有消费者，确认没有带入新的栏位、焦点或滚动问题。避免把样式重构扩展到数据模型、存储或后台调用的改动。

先完成构建和隔离预览，再按授权同步到 ST。同步后以真实宿主检查全局样式影响；提交时只包含本轮文件，并说明变化和验证结果。页面优化方案与实际完成状态分别记录，完成一个页面后再更新覆盖范围。

## 验收标准

每个页面至少检查 360、390、430px 窄屏和 1280px 桌面视口，同时覆盖桌面窄面板、420px 高度的短视口、深浅色、大字号以及 Liquid Glass 开关。长标题、多分类、长列表、短列表、空数据、错误和处理中状态都应能正常阅读和操作。

重点验证首项不被顶栏挡住、末项能完整滚到栏上方、多行扩展自动计入栏高、短内容底栏位置稳定，以及详情返回、翻页、筛选后的滚动行为。键盘 Tab 顺序应自然，图标有名称，展开区可用 Enter 或 Space 操作，未保存修改与删除确认行为保持。软键盘覆盖需在实际移动浏览器或对应环境验证，不把桌面短视口检查等同于真机验证。

验证深度随改动选择：类型检查与相关 Lint、受影响的行为测试、实际浏览器交互。视觉样式以截图和交互验证为主，不添加只复述 className 或内部实现的测试。

现有隔离预览在 `.scratch/ui-mobile-redesign/`：`check.cjs` 覆盖页面及主要业务交互，`layout-check.cjs` 覆盖动态栏高和短视口，`glass-check.cjs` 覆盖外观开关，`glass-compat-check.cjs` 覆盖 Chrome 渐变边缘和宿主文字阴影，`record-actions-check.cjs` 覆盖记录删除及脏保护，`tables-check.cjs` 覆盖表格单列导航、字段编辑删除、依赖限制、创建删除、编辑保存与失败保留草稿。`tasks-check.cjs` 覆盖填表触发/取消/重试、楼层标记确认、向量筛选/分页/详情/批量取消及类型切换的底栏隔离。运行条件见该目录 README；涉及真实 ST 数据的脚本需使用专门测试环境。

## 代码入口

公共容器见 [page-layout.tsx](../../src/ui/shell/page-layout.tsx)，栏和图标操作见 [panel-bar.tsx](../../src/ui/shell/panel-bar.tsx)，展开区见 [disclosure.tsx](../../src/ui/shell/disclosure.tsx)。视觉参数见 [tokens.css](../../src/ui/styles/tokens.css)，公共布局和材质见 [panel-shell.css](../../src/ui/styles/panel-shell.css)。记录页的调用方式见 [record-view.tsx](../../src/ui/memory/record-view.tsx)，分组样式见 [records.css](../../src/ui/styles/records.css)。

表格管理的编辑模式使用铅笔入口，字段行提供删除动作，依赖字段禁删；不再展示上下移动按钮。表格配置的展开状态在当前表内保留，切表重置。配置子页以左箭头返回，保留未保存确认；创建与字段编辑使用取消按钮。新建表与关闭面板共用顶栏右侧操作组，正文不再展示表数量。

字段行的 Hover/Active 背景由整行容器承担，覆盖文字、留白和开关区域；文字编辑、开关与删除保持独立点击目标。顶底栏操作组支持 `auto`、`none`、`always` 框样式：PanelBar 使用 leadingFrame/trailingFrame，PanelBottomBar 使用 mainFrame/trailingFrame。默认 auto，直接子控件标记 `data-bar-unframed` 时去掉胶囊背景、边框、阴影与模糊；always 强制保留胶囊，none 强制移除。表格启用开关使用无框标记。

任务页楼层覆盖放在手动触发区域下方并默认展开；任务类型切换使用公共 Tabs 的胶囊样式。


## 本轮覆盖状态

设置、检索、问答与日志已接入统一页面规范。设置采用分组分类和返回导航，连接及表格预设采用编辑顶栏；检索采用分组结果和按需展开配置；问答使用标准输入底栏；日志使用 Key 搜索、折叠筛选及分组原文。上述页面保留原有业务服务与数据契约。

新增页面也遵循同一套规则：正文只保留主要工作路径，次要设置由 Disclosure 承载，顶栏图标提供页面操作。隐藏挂载页面必须显式停止声明 PageChrome；嵌套编辑切换期间公共容器以活动声明计数控制默认顶栏，防止默认栏重复出现。模式切换使用 Tabs，业务 data-* 标记通过 dataAttributes 传入。

隔离预览补充了长篇流式问答和多级别日志样例，用于验证回看位置、停止、模式历史、固定输入栏、筛选及清理。页面切换还需验证顶栏图标与底栏随页面退出正确卸载。浏览器短视口检查覆盖布局，真实移动软键盘仍按前述验收标准单独验证。


## 设置对象导航重构

宏、表格预设、Agent 预设与清洗规则采用对象列表 → 详情 → 独立编辑的单列导航。列表共用分组 surface、两行摘要和进入箭头；创建、主要操作由标准顶栏承担。宏表单隐藏父作用域标签与列表，取消和保存固定在顶栏，保留删除、已保存输出预览与复制。选择表后才出现筛选和显示字段。

表格预设列表优先展示预设，默认选择、当前空间应用和另存结构按需展开。预设详情进入表列表，再查看字段说明；完整结构仅在主动预览时展示。编辑预设同样从表列表进入字段列表，再打开独立表或字段表单。完成子表单更新预设草稿，整体保存后才写入预设库；顶栏持续标识未保存状态，取消字段编辑同时丢弃该字段尚未完成的约束。

Agent 预设浏览详情独立于实际使用选择，通过「设为当前预设」明确激活。消息编辑、清洗列表开关沿用即时保存，使用返回动作；宏和清洗规则草稿使用取消、保存与离开保护。排序、导入、预览、清洗测试和删除均保留在对象所属页面。危险动作继续说明影响并确认。

独立编辑每次从顶部打开，返回恢复对应对象列表的滚动位置，表单不会复用其他对象的滚动位置。外观继续以真实主题、强调色和字体样本表达选中状态；安全区以四向输入展示对应边界。

设置按对象列表→直接编辑组织操作：Agent消息与连接表单显式保存，新增取消不创建对象；开关与排序即时生效。名称创建/修改使用独立表单，低频管理放顶栏菜单。动态顶栏用PageChrome的pageKey分离页面身份，防止跨页复用点击目标。当前操作流通过cua_repl在390px视口验收；历史settings浏览器脚本涉及逐键保存、原生名称prompt或旧操作区时，须先适配新保存语义，不能沿用旧通过结论。
