# 移动端 UI

本轮以 `feat/redesign` 的墨灰主题和表格工作台为基础，在当前业务能力上重构界面。

## 导航和页面

面板默认进入记录。抽屉分为日常使用（记录、检索、问答、任务）与管理（表格、设置、日志）。当前空间显示在标题下，异常上下文单独提示。导航打开时约束键盘焦点，关闭后回到触发按钮。

记录默认摘要列表，支持完整详情、来源证据、修订历史与独立编辑；批量编辑保留网格。记录详情返回恢复当前列表滚动位置。表格在窄面板下采用索引与详情两级导航，宽面板采用双栏；详情分为字段、表格信息、显示策略和向量索引。设置采用分类列表与单组详情。任务分为填表和向量两类。检索把搜索选项、索引诊断与召回配置收拢，保留查询和结果的主路径。

## 视觉与组件

颜色、字体、字号和控件尺寸集中在 `src/ui/styles/tokens.css`。组件使用语义令牌，旧 `--stm-ink*` 名称暂时作为别名。派生字号和颜色必须在面板上重新计算，以响应主题与字号变化。`color-scheme` 仅作用于插件面板，避免影响宿主。

系统字体为默认，深浅主题均支持青绿、蓝色、靛蓝和中性强调色。外观保存在当前浏览器的 `ste-memory.appearance.v1`，不进入记忆备份。公共按钮、分段选择器和导航样式放在 `panel-shell.css`；模块只负责自己的布局。主要触控目标至少 44px，手机文本输入至少 16px。

组件继续使用 React 和现有 CSS，没有新增运行时依赖。面板保留 manual popover 顶层及桌面拖动、缩放、安全区能力。表格布局以 `stm-panel` 容器宽度 640px 为界，避免桌面窄窗口仍强制双栏。

界面优先通过布局、选中状态与操作入口解释功能。避免重复标题、字段值和常驻教程；技术细节与复杂语法放入按需展开的说明。错误、必要输入限制和危险操作影响保留在对应操作附近。表格与字段编辑使用原生 `dialog` 管理焦点和键盘关闭。

## 验证

运行类型检查、Lint、Vitest 和构建。隔离预览位于 `.scratch/ui-mobile-redesign/`，使用真实组件和内存样例，刷新重置，不连接聊天数据。浏览器验收检查小屏和桌面布局、深浅色、大字号、列表到详情再返回、表单保存取消、设置分类与任务切换。

真实 SillyTavern 验收脚本位于 `docs/playwright-st-extension/`。这些脚本可能创建、修改或清理测试角色数据，运行前应使用专门的测试环境。

## 记录页与公共顶栏基线

记录列表采用单行标题与单行摘要，整行可点，来源、时间和字段全量内容放在详情。分页停靠滚动区域底部，短列表仍贴底，详情返回恢复列表位置，翻页回到列表顶部。详情和编辑沿用同一顶栏，编辑的取消、保存固定在栏内。

一级页面、表格详情和记录详情共用 `PanelBar` 的 leading / title / subtitle / trailing 槽位。顶栏最小高度 60px，触控目标 44px；背景、边框、阴影与 backdrop 分开定义，后续可集中添加玻璃效果，不需要逐页改结构。默认采用实色背景，Liquid Glass 开关统一切换顶底栏材质。

| 类别 | 基线 |
| --- | --- |
| 字号 | 12 / 13 / 15 / 17px，通过 font-scale 统一缩放 |
| 字重 | regular 400 / medium 500 / semibold 600 |
| 行高 | tight 1.3 / normal 1.5 / relaxed 1.65 |
| 间距 | space-1～6：4 / 8 / 12 / 16 / 20 / 24px |
| 页面与列表 | page-padding 16px，row-padding-y 12px |
| 颜色 | fg / fg-2 / fg-3 表示主次文本；surface 与 border 表示层级；accent 表示操作与选中 |
| 顶栏材质 | bar-bg / bar-border / bar-shadow / bar-backdrop |

后续页面重构沿用这些令牌；大字号、深浅色与窄面板下保持相同的层级和操作位置。

## 标准顶栏扩展

`PanelBar` 管理居中标题、两侧操作组与材质。`PanelBarAction` 提供标准图标操作，必填 `icon`、`label`，支持原生按钮的提交、禁用、ref 和事件属性；`label` 同时用于辅助技术名称与悬停提示。`leading`、`trailing` 可组合多个标准操作，也可插入页面专属控件（如表格启用开关）。`extension` 为标题下方的全宽区域，可放搜索或筛选。移动端每侧建议最多两个快捷操作，其余操作由页面收进菜单。

Liquid Glass 由外观设置控制并存于本机。顶栏背景使用向下淡出的主题色层，按钮组单独使用带背景模糊的圆形／胶囊玻璃容器。背景层不拦截点击，图标操作保留 44px 触控区域。该实现使用网页 CSS 材质，不包含原生系统的光学折射。

## 底部操作栏

`PanelBottomBar` 复用 `PanelBarAction` 和胶囊材质，主区域接收操作与状态文字，`trailing` 放独立快捷操作。记录页采用上一页图标、页码、下一页图标组成的分页胶囊，旁边是新建按钮；批量编辑下该按钮添加新行。页码变化通过 aria-live 告知辅助技术。底栏由 PageLayout 固定在容器底部，容器按实际栏高为最后一条记录留出空间并处理设备安全区。Liquid Glass 开启时使用向上淡出的主题色层，关闭时恢复实色。

## 页面容器

`PageLayout` 接收 `header`、`footer` 和内容槽位，集中管理滚动、栏定位、内容留白与安全区。实色模式让顶栏、内容和底栏自然分区；玻璃模式允许内容从栏下经过，并通过 ResizeObserver 测量栏的实际高度，自动更新内容避让。顶栏增加第二行、底栏变化或字号切换时，页面无需手动计算高度。

普通页面共用 shell 的内容滚动区。记录页通过页面栏槽位替换默认顶栏、设置分页底栏；详情与编辑退出时恢复默认栏。编辑保存按钮使用 HTML form 关联提交对应表单。表格工作台使用 contained 模式保留双栏和内部滚动。页面内容不再写安全区、负边距或固定栏高补偿。

隔离浏览器验证 `layout-check.cjs` 覆盖动态多行顶栏、底栏高度变化、短视口、玻璃／实色切换与编辑页栏切换；`check.cjs` 继续验证列表定位、末条可见性和原有业务操作。

## 记录分组与详情操作

记录列表和详情字段采用圆角 surface 分组、内缩分隔线；列表保持单行标题与单行摘要，字号继续响应外观缩放。`Disclosure` 统一修订历史和向量索引的原生展开行为、图标、标题、状态、箭头与内容区域。

详情和编辑状态通过 `PageChrome` 声明顶栏操作。已保存记录的删除与编辑／保存共用右侧操作组，新建表单不显示删除。删除保留未保存修改保护与二次确认，操作期间禁用相关控件，完成后退出详情／编辑回到列表。

## 宿主样式与 Chromium 兼容

插件面板及子元素统一清除 `text-shadow`，隔离 SillyTavern 通配样式的文字阴影。顶底栏大背景仅使用 48px 渐变色过渡，避免 Chromium 对 backdrop-filter 与渐变 mask 同层合成时产生的硬边；按钮胶囊保留真实 backdrop blur。各平台共用此实现，无 UA 判断。`glass-compat-check.cjs` 在 Windows Chrome 下用高反差条纹做像素边缘检查，并注入宿主文字阴影验证隔离；需要 Python Pillow。

记录工具区采用整行横滑表标签，下方左侧显示计数或搜索输入，右侧放图标视图切换与搜索。批量保存／放弃操作仅在批量模式出现。
