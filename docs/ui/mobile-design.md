# 移动端 UI

后续页面统一改造遵循 [界面统一优化方案](ui-optimization-plan.md)；本文保留现有实现细节。

本轮以 `feat/redesign` 的墨灰主题和表格工作台为基础，在当前业务能力上重构界面。

## 导航和页面

面板默认进入记录。导航分为日常使用（记录、检索、问答、任务）与管理（表格、设置、日志）。导航是否常驻按**面板自身宽度**判断：宽度 ≥ 640px 时默认固定在左侧与内容并排，顶栏汉堡按钮收起导航后内容接管整块宽度；窄于 640px（包括桌面窗口缩到手机大小）时回到覆盖内容的抽屉。当前空间显示在标题下，异常上下文单独提示。抽屉打开时约束键盘焦点，关闭后回到触发按钮。

记录默认摘要列表，支持完整详情、来源证据、修订历史与独立编辑；批量编辑保留网格。记录详情返回恢复当前列表滚动位置。表格在所有尺寸下采用单列列表与详情导航；详情优先展示字段，表格信息、显示策略和向量索引从配置区进入。设置采用分类列表与单组详情。任务分为填表和向量两类。检索把搜索选项、索引诊断与召回配置收拢，保留查询和结果的主路径。

## 视觉与组件

颜色、字体、字号和控件尺寸集中在 `src/ui/styles/tokens.css`。组件使用语义令牌，旧 `--stm-ink*` 名称暂时作为别名。派生字号和颜色必须在面板上重新计算，以响应主题与字号变化。`color-scheme` 仅作用于插件面板，避免影响宿主。

系统字体为默认，主题提供墨灰、午夜蓝、松林、瓷白、沙丘五种预设，也可自定义主题色与强调色；强调色另含青绿、蓝色、靛蓝、紫罗兰、玫瑰、琥珀和中性预设。界面样式分为 Liquid Glass（默认）、Classic 与 Material（MD3）三种，不再单独切换亮色/暗色。外观保存在当前浏览器的 `ste-memory.appearance.v2`，旧版 `v1` 设置会自动迁移。公共按钮、分段选择器和导航样式放在 `panel-shell.css`；模块只负责自己的布局。主要触控目标至少 44px，手机文本输入至少 16px。

组件继续使用 React 和现有 CSS，没有新增运行时依赖。面板保留 manual popover 顶层及桌面拖动、缩放、安全区能力。表格管理沿用单列页面，不因桌面或宽面板切换成左右分栏。

界面优先通过布局、选中状态与操作入口解释功能。避免重复标题、字段值和常驻教程；技术细节与复杂语法放入按需展开的说明。错误、必要输入限制和危险操作影响保留在对应操作附近。表格与字段编辑沿用页面顶栏保存、取消和删除，离开时保护未保存的修改。

## 验证

运行类型检查、Lint、Vitest 和构建。隔离预览位于 `.scratch/ui-mobile-redesign/`，使用真实组件和内存样例，刷新重置，不连接聊天数据。浏览器验收检查小屏和桌面布局、三种界面样式与各预设主题、大字号、列表到详情再返回、表单保存取消、设置分类与任务切换。

真实 SillyTavern 验收脚本位于 `docs/playwright-st-extension/`。这些脚本可能创建、修改或清理测试角色数据，运行前应使用专门的测试环境。

## 记录页与公共顶栏基线

记录列表采用单行标题与单行摘要，整行可点，来源、时间和字段全量内容放在详情。分页停靠滚动区域底部，短列表仍贴底，详情返回恢复列表位置，翻页回到列表顶部。详情和编辑沿用同一顶栏，编辑的取消、保存固定在栏内。

一级页面、表格详情和记录详情共用 `PanelBar` 的 leading / title / subtitle / trailing 槽位。顶栏最小高度 60px，触控目标 44px；背景、边框、阴影与 backdrop 分开定义，后续可集中添加玻璃效果，不需要逐页改结构。默认采用 Liquid Glass，可在外观设置切换为 Classic（实色）或 Material（MD3）。

| 类别 | 基线 |
| --- | --- |
| 字号 | 12 / 13 / 15 / 17px，通过 font-scale 统一缩放 |
| 字重 | regular 400 / medium 500 / semibold 600 |
| 行高 | tight 1.3 / normal 1.5 / relaxed 1.65 |
| 间距 | space-1～6：4 / 8 / 12 / 16 / 20 / 24px |
| 页面与列表 | page-padding 16px，row-padding-y 12px |
| 颜色 | fg / fg-2 / fg-3 表示主次文本；surface 与 border 表示层级；accent 表示操作与选中 |
| 顶栏材质 | bar-bg / bar-border / bar-shadow / bar-backdrop |

后续页面重构沿用这些令牌；大字号、任意主题底色与窄面板下保持相同的层级和操作位置。

## 标准顶栏扩展

`PanelBar` 管理居中标题、两侧操作组与材质。`PanelBarAction` 提供标准图标操作，必填 `icon`、`label`，支持原生按钮的提交、禁用、ref 和事件属性；`label` 同时用于辅助技术名称与悬停提示。`leading`、`trailing` 可组合多个标准操作，也可插入页面专属控件（如表格启用开关）。`extension` 为标题下方的全宽区域，可放搜索或筛选。移动端每侧建议最多两个快捷操作，其余操作由页面收进菜单。

Liquid Glass 为默认界面样式，由外观设置切换并存于本机。顶栏背景使用向下淡出的主题色层（16px 渐变），按钮组单独使用带背景模糊的圆形／胶囊玻璃容器；内容不再额外下移。背景层不拦截点击，图标操作保留 44px 触控区域。该实现使用网页 CSS 材质，不包含原生系统的光学折射。

## 底部操作栏

`PanelBottomBar` 复用 `PanelBarAction` 和胶囊材质，主区域接收操作与状态文字，`trailing` 放独立快捷操作。记录页采用上一页图标、页码、下一页图标组成的分页胶囊，旁边是新建按钮；批量编辑下该按钮添加新行。页码变化通过 aria-live 告知辅助技术。底栏由 PageLayout 固定在容器底部，容器按实际栏高为最后一条记录留出空间并处理设备安全区。Liquid Glass 样式使用向上淡出的主题色层，Classic 与 Material 恢复实色。

## 页面容器

`PageLayout` 接收 `header`、`footer` 和内容槽位，集中管理滚动、栏定位、内容留白与安全区。实色模式让顶栏、内容和底栏自然分区；玻璃模式允许内容从栏下经过，并通过 ResizeObserver 测量栏的实际高度，自动更新内容避让。顶栏增加第二行、底栏变化或字号切换时，页面无需手动计算高度。

普通页面共用 shell 的内容滚动区。记录页通过页面栏槽位替换默认顶栏、设置分页底栏；详情与编辑退出时恢复默认栏。编辑保存按钮使用 HTML form 关联提交对应表单。表格管理在所有尺寸使用单列列表与详情导航，共用 shell 滚动区，通过 PageChrome 切换顶栏。页面内容不再写安全区、负边距或固定栏高补偿。

隔离浏览器验证 `layout-check.cjs` 覆盖动态多行顶栏、底栏高度变化、短视口、玻璃／实色切换与编辑页栏切换；`check.cjs` 继续验证列表定位、末条可见性和原有业务操作。

## 记录分组与详情操作

记录列表和详情字段采用圆角 surface 分组、内缩分隔线；列表保持单行标题与单行摘要，字号继续响应外观缩放。`Disclosure` 统一修订历史和向量索引的原生展开行为、图标、标题、状态、箭头与内容区域。

详情和编辑状态通过 `PageChrome` 声明顶栏操作。已保存记录的删除与编辑／保存共用右侧操作组，新建表单不显示删除。删除保留未保存修改保护与二次确认，操作期间禁用相关控件，完成后退出详情／编辑回到列表。

## 宿主样式与 Chromium 兼容

插件面板及子元素统一清除 `text-shadow`，隔离 SillyTavern 通配样式的文字阴影。顶底栏大背景仅使用 16px 渐变色过渡，避免 Chromium 对 backdrop-filter 与渐变 mask 同层合成时产生的硬边；按钮胶囊保留真实 backdrop blur。各平台共用此实现，无 UA 判断。`glass-compat-check.cjs` 在 Windows Chrome 下用高反差条纹做像素边缘检查，并注入宿主文字阴影验证隔离；需要 Python Pillow。

记录工具区采用整行横滑表标签，下方左侧显示计数或搜索输入，右侧放图标视图切换与搜索。批量保存／放弃操作仅在批量模式出现。

## 触屏交互

Hover 仅在支持悬停的精细指针设备启用，触屏保留按压与选中状态。标准图标按钮由 PanelBarAction 统一管理按下和释放，按住任一按钮时，所属胶囊 Panel 连同所有子组件整体放大，按钮自身不单独缩放；按压缩放与时长使用 `--stm-press-scale`（1.035）和 `--stm-press-duration`（120ms）。松开、取消或移出时恢复，禁用状态不响应。Liquid Glass 下页面 Tab 与导航 Tab 使用玻璃表面并按同一令牌放大；Chip 保持纯色背景与边框，不叠加玻璃材质。键盘焦点继续可见，减少动态效果模式仅保留颜色反馈。工具区图标也使用相同组件，避免页面各写一套。

表格列表的新建操作通过 `PageChrome.headerTrailing` 接入默认顶栏右侧胶囊。记录、表格及字段列表共用 `stm-grouped-list` 的边框和背景；搜索输入与列表圆角均使用统一的 14px Token。字段管理采用编辑模式行内删除，表格配置以静态分组列表展示三项入口，配置子页使用左箭头返回。

向量索引页按状态、规则、预览三段组织：状态卡用开关和覆盖条表达启用状态与「记录 → 向量」分布，规则卡用分段控件选择字段来源与更新方式，字段组合以芯片按顺序展示；输入预览与索引维护默认收起，展开后滚入可视区。来源为自动时字段顺序只读，自定义时分组芯片可拖动排序。

## 任务页

任务页沿用单一滚动容器。填表与向量的类型切换保留输入、筛选和展开状态，隐藏页面停止轮询并停止声明 PageChrome，避免底栏跨类型显示。填表页优先展示触发范围、活动进度及最近结果，楼层覆盖紧随手动触发区域且默认展开，配置、初始化和楼层标记按需展开；活动任务的日志与取消放在标准底栏。向量页按状态筛选，其他筛选集中于 Disclosure，任务使用整行 Hover 的分组列表，详情显示完整错误及输入原文，分页与批量取消固定在底栏。处理中禁用冲突操作，轮询更新不重置列表滚动。

任务类型切换复用公共 `Tabs`，内外均采用胶囊圆角，支持左右方向键及 Home/End 切换，保留 tablist/tab/tabpanel 语义。

## 设置、检索、问答与日志

设置首页按记忆与提示词、模型连接、界面、数据与运行分组，分类条目使用公共分组边框、主次文本和整行反馈。详情使用标准返回顶栏；连接及表格预设的草稿编辑使用顶栏保存、取消，保留未保存确认。记忆宏按「全局宏 / 对话宏 / 内置宏」三作用域组织，宏前缀、输出上限与使用说明收进独立「宏设置」页；摘要条常驻显示当前宏表达式、默认快照体积与截断状态，列表行提供可复制的宏表达式。说明与语法帮助按需展开，危险操作保留影响说明与确认。

检索正文优先展示查询与结果，搜索选项、连接、诊断与召回配置使用 Disclosure。结果整行进入记录详情，组分与来源独立展开；索引操作放顶栏。隐藏挂载的检索页通过 active 停止声明栏位，避免影响其他页面。

问答模式复用 Tabs，刷新记录放顶栏；单行输入及发送／停止通过 PageChrome 声明底栏，内容避让交给 PageLayout。流式输出仅在接近底部时跟随，回看历史时保持位置，发送和切换空间／模式后滚到底部。思考与工具调用沿用既有流式展开规则，完整错误与提交结果继续展示。

日志将 Key 搜索放在主路径，类型与级别放入 Disclosure；结果采用紧凑分组行，展开后原样显示日志并可复制。清空入口位于顶栏，确认说明覆盖全部日志。查询与清空期间显示处理状态并禁用冲突操作。

PageLayout 使用活动顶栏声明计数管理默认栏显隐，确保父详情与子编辑在同次渲染中交接时，父声明清理不会重新显示默认栏。每个页面状态仍只声明一个完整顶栏；计数用于生命周期交接，不用于叠加多个完整顶栏。Tabs 可通过 dataAttributes 保留业务自动化标记，选中、键盘与圆角行为继续集中维护。


## 设置对象导航重构

宏、表格预设、Agent 预设与清洗规则采用对象列表 → 详情 → 独立编辑的单列导航。列表共用分组 surface、两行摘要和进入箭头；创建、主要操作由标准顶栏承担。宏表单隐藏父作用域标签与列表，取消和保存固定在顶栏，保留删除、已保存输出预览与复制。选择表后才出现筛选和显示字段。

表格预设列表优先展示预设，默认选择、当前空间应用和另存结构按需展开。点击任意预设先进入只读详情，再进入表列表和复用记忆表格页的字段与配置详情；顶栏编辑动作才打开草稿，内置预设编辑时复制为用户预设。完整结构仅在主动预览时展示。编辑预设同样从表列表进入字段列表，再打开独立表或字段表单。完成子表单更新预设草稿，整体保存后才写入预设库；顶栏持续标识未保存状态，取消字段编辑同时丢弃该字段尚未完成的约束。

Agent 预设浏览详情独立于实际使用选择，通过「设为当前预设」明确激活。消息编辑、清洗列表开关沿用即时保存，使用返回动作；宏和清洗规则草稿使用取消、保存与离开保护。排序、导入、预览、清洗测试和删除均保留在对象所属页面。危险动作继续说明影响并确认。

独立编辑每次从顶部打开，返回恢复对应对象列表的滚动位置，表单不会复用其他对象的滚动位置。外观继续以真实主题、强调色和字体样本表达选中状态；安全区以四向输入展示对应边界。

设置按对象列表→直接编辑组织操作：Agent消息与连接表单显式保存，新增取消不创建对象；开关与排序即时生效。名称创建/修改使用独立表单，低频管理放顶栏菜单。动态顶栏用PageChrome的pageKey分离页面身份，防止跨页复用点击目标。当前操作流通过cua_repl在390px视口验收；历史settings浏览器脚本涉及逐键保存、原生名称prompt或旧操作区时，须先适配新保存语义，不能沿用旧通过结论。
