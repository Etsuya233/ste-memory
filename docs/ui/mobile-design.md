# 移动端 UI

本轮以 `feat/redesign` 的墨灰主题和表格工作台为基础，在当前业务能力上重构界面。

## 导航和页面

面板默认进入记录。抽屉分为日常使用（记录、检索、问答、任务）与管理（表格、设置、日志）。当前空间显示在标题下，异常上下文单独提示。导航打开时约束键盘焦点，关闭后回到触发按钮。

记录默认摘要列表，支持完整详情、来源证据、修订历史与独立编辑；批量编辑保留网格。记录详情返回恢复当前列表滚动位置。表格在窄面板下采用索引与详情两级导航，宽面板采用双栏；详情分为字段、表格信息、显示策略和向量索引。设置采用分类列表与单组详情。任务分为填表和向量两类。检索把搜索选项、索引诊断与召回配置收拢，保留查询和结果的主路径。

## 视觉与组件

颜色、字体、字号和控件尺寸集中在 `src/ui/styles/tokens.css`。组件使用语义令牌，旧 `--stm-ink*` 名称暂时作为别名。派生字号和颜色必须在面板上重新计算，以响应主题与字号变化。`color-scheme` 仅作用于插件面板，避免影响宿主。

系统字体为默认，深浅主题均支持青绿、蓝色、靛蓝和中性强调色。外观保存在当前浏览器的 `ste-memory.appearance.v1`，不进入记忆备份。公共按钮、分段选择器和导航样式放在 `panel-shell.css`；模块只负责自己的布局。主要触控目标至少 44px，手机文本输入至少 16px。

组件继续使用 React 和现有 CSS，没有新增运行时依赖。面板保留 manual popover 顶层及桌面拖动、缩放、安全区能力。表格布局以 `stm-panel` 容器宽度 640px 为界，避免桌面窄窗口仍强制双栏。

界面优先通过布局、选中状态与操作入口解释功能。避免重复标题、字段值和常驻教程；技术细节与复杂语法放入按需展开的说明。错误、必要输入限制和危险操作影响保留在对应操作附近。表格与字段编辑使用原生 `dialog` 管理焦点和键盘关闭。

## 验证

运行类型检查、Lint、Vitest 和构建。隔离预览位于 `.scratch/ui-mobile-redesign/`，使用真实组件和内存样例，刷新重置，不连接聊天数据。浏览器验收检查小屏和桌面布局、深浅色、大字号、列表到详情再返回、表单保存取消、设置分类与任务切换。

真实 SillyTavern 验收脚本位于 `docs/playwright-st-extension/`。这些脚本可能创建、修改或清理测试角色数据，运行前应使用专门的测试环境。
