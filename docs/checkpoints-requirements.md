# 记忆历史版本与手动恢复需求

日期：2026-11-11。状态：需求已确认，尚未实现。

## 目标与范围

用户可以保存当前记忆空间，也可以由插件在填表成功后自动保存历史版本；需要回退时，从当前聊天的历史版本列表中选择并手动恢复。每个版本保存一份完整空间快照，复用现有备份格式和空间导入流程。

历史版本保存在当前浏览器的 IndexedDB，按聊天归属管理。历史列表独立于活动记忆空间，恢复、导入或重建空间后仍可查看该聊天原有版本。历史副本不随聊天文件同步，换设备或浏览器无法直接看到；用户可以导出备份文件自行转移。清除站点数据会丢失本机历史。

这项需求扩展了 [ADR 0033](./adr/st/0033-chat-file-only-memory.md) 对 IndexedDB 存储内容的限制，新增独立历史备份集合。当前活动空间仍以聊天文件为持久化来源，本机历史只在用户明确恢复时应用，不参与启动时的自动恢复或覆盖；实施时需同步补充相关架构决策。

功能只恢复插件的记忆空间。首版允许用户选择当前聊天下任意保留版本，通过时间和填表进度判断是否适用，不执行聊天正文匹配，不自动响应删楼、改写、swipe、分支或 ST Checkpoint。启用前的历史状态无法补造，也不支持任意楼层的精确回退。

## 历史版本保存什么

版本内容沿用完整空间备份，修订历史随快照保存，本轮不增加省略修订历史的开关。保存对象为受管的已提交状态，编辑草稿、未提交提案和 SQL 控制台未纳入受管提交的修改不进入版本。

| 内容 | 恢复行为 |
| --- | --- |
| 表格、字段、显示策略、填写配置、表级向量配置 | 恢复版本中的定义 |
| 记忆记录、修订历史、字段证据、初始化来源 | 恢复版本中的内容 |
| 对话宏 | 恢复版本中的定义 |
| 填表进度 | 与记忆内容一起恢复，保留已处理、出错和未跟踪的真实分布 |
| ST 聊天正文、swipe、隐藏状态 | 保持当前状态 |
| 全局设置、连接、密钥、角色卡、世界书及独立聊天配置 | 保持当前状态 |
| 填表任务、向量、助手会话及未提交提案 | 沿用现有空间替换的停止与清理规则，不作为历史数据恢复 |
| 页面草稿、查询结果与求值缓存 | 不恢复，旧空间内容失效 |

记录级修订历史继续提供单条记录的查看和“恢复到编辑”。空间历史版本使用完整快照恢复整个空间，两种功能同时保留。

## 压缩存储

手动版本、填表自动版本和恢复前版本统一使用 gzip 无损压缩。完整快照序列化为 UTF-8 JSON 后压缩，以二进制保存到 IndexedDB，避免 Base64 带来的额外体积。每份版本可独立解压和恢复，不依赖其他历史版本；删除或淘汰版本不会影响剩余版本。

版本名称、保存时间、来源、记录数量及填表进度摘要与压缩载荷分别存储，浏览列表无需解压全部历史。保存时记录存储格式版本、压缩算法以及压缩前后字节数，详情展示实际存储大小。压缩不裁剪修订历史或其他备份内容，自动版本仍按配置的份数保留，用户可按实际空间占用调高上限。

恢复和导出时先解压所选版本，再沿用现有备份校验与迁移流程。导出仍生成现有格式的 JSON 备份文件，现有导入入口无需增加 gzip 文件支持。压缩失败按对应保存操作的失败规则处理，不静默改为未压缩保存；解压失败或压缩格式不支持时明确报错，保留历史原数据，不应用损坏内容。

## 保存方式与默认配置

| 配置 | 默认值 | 规则 |
| --- | --- | --- |
| 自动保存 | 开启 | 关闭后停止新增填表自动版本，已有版本保留 |
| 自动保存间隔 | 10 层 | 可配置为正整数，按新增处理的不同楼层累计 |
| 自动版本保留数量 | 每个聊天 20 份 | 可配置为正整数，填表自动版本与恢复前版本共同计数 |

这些配置作为全局设置生效，首版不增加逐聊天覆盖。手动版本不计入自动版本上限，保留到用户主动删除。

### 手动保存

用户点击“保存版本”，可填写名称；未填写时使用包含保存时间的默认名称。保存成功后立即出现在当前聊天的历史列表中。重复手动保存允许形成独立版本，用户可以自行删除。

手动保存不推进自动保存间隔的计数。正在提交的数据需完成事务后才能捕获，保存结果必须对应一份完整已提交状态。

### 自动保存

首次完整填表成功并完成当前空间保存后，创建一份自动版本；以后在新增处理楼层数达到间隔时，于一次完整填表任务成功并保存后创建版本。手动填表和自动填表均适用；初始化填表成功也可建立首份自动版本。

用户消息和 AI 消息都按楼层计数。同一累计周期中重复处理同一楼层不重复计数，只有新增成功处理的楼层推进累计；手工标记进度不触发保存，也不计作填表成果。刷新和切换聊天保留累计状态。

例如间隔为 10 层，某次任务新增处理 6 层，下一次新增处理 7 层，则在第二次任务结束时保存一份，并从这次保存重新累计。一项任务跨过多个间隔，也只保存其完整成功后的最终状态。

失败或取消的任务不创建自动版本，也不将其部分完成批次计入本次自动保存累计；现有部分提交和进度保持原有行为。恢复历史版本后，以恢复后的进度重新建立累计基准；显式导入或重建空间也重新建立基准，不沿用被替换空间的累计。

手动编辑、追加聊天消息、刷新、切换聊天、强制同步、普通导入和重复保存重试均不直接触发填表自动版本。自动保存开关不影响手动保存及恢复前备份。

## 查看、导出与删除

在设置的备份与空间维护区域提供当前聊天的“历史版本”入口。列表按保存时间从新到旧排列，展示版本名称、时间、来源、记录数量与填表进度。来源区分“手动保存”“填表自动保存”“恢复前保存”。进度详情应能表达空洞，不能把最大已处理楼层展示为全部连续完成。

每个版本均支持查看摘要、改名、导出、恢复和删除。改名只修改名称，不改变版本内容、来源或淘汰规则；删除需确认，仅删除历史副本，不改变当前记忆空间。

手动版本、填表自动版本和恢复前版本都可以导出。导出内容来自所选版本保存时的完整快照，采用现有单空间备份文件格式，可通过现有导入功能恢复。文件名包含聊天名称、版本名称和版本保存时间，并处理文件名不可用字符。导出操作不改变版本内容，也不产生新版本；首版不提供整段历史打包。

普通“导出当前空间”继续导出当前状态。通过备份文件导入只替换当前空间，不自动导入整个历史列表。

## 手动恢复流程

用户选中版本后，界面展示版本摘要、将替换的空间内容，以及任务、向量和助手会话等清理影响。用户确认后，沿用现有空间替换流程停止旧工作并等待事务结束，先保存恢复前的完整已提交状态，再应用目标快照。若准备期间当前状态发生变化，应刷新摘要并重新确认。

恢复前保存的版本标记为“恢复前保存”，即使关闭填表自动保存也必须创建。该版本归入自动版本数量限制，但本次恢复结束前不得被淘汰；正在恢复的目标版本在本次操作结束前也必须保持可用。必要时允许暂时超出数量上限，操作结束后再按保留规则裁剪。

恢复复用现有备份校验、迁移、克隆、空间替换、聊天文件保存和回读核验流程，保持引用关系完整。用户确认的是具体聊天和具体版本；切换聊天或替换空间后，旧确认失效。运行中的旧任务及迟到响应不能覆盖恢复后的状态。

恢复成功后，当前记忆和填表进度切换到目标版本，历史列表继续保留。恢复操作本身不再额外生成一份目标内容的自动版本。用户若选错，可以再次选择“恢复前保存”的版本恢复；该操作仍遵循同一恢复流程。

## 保留与失败行为

自动类版本超过上限时，按保存时间删除最旧版本；手动版本不参与淘汰。下调上限后按新数量裁剪，关闭自动保存不删除已有版本。只有新版本成功持久化后才淘汰旧版本，避免保存失败导致历史减少。

手动保存失败时显示具体错误，不显示成功版本。填表自动备份失败时提示错误，已完成的填表结果继续保留，不因历史副本失败回滚或重跑填表；自动保存累计在备份成功后才重置。可重试保存同一快照，不能把后来变化的状态标为原任务的历史版本。

恢复前备份失败时停止恢复，保留当前空间。目标版本损坏或不支持其格式时明确报错，保留原数据。空间替换后的保存或核验失败，沿用现有“已载入但未核验保存”的状态及重试流程，不能报告恢复完成；重试同一次操作不重复创建恢复前版本或重新克隆目标。

本机存储不足时提示清理历史或导出备份，不自动删除手动版本。所有保存、恢复、导出和删除操作保持聊天归属，空间替换中的旧辅助数据清理不得删除历史版本列表。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 手动保存后编辑记录，再恢复 | 结构、记录、修订、证据、宏与进度恢复为所选快照；聊天正文保持当前状态 |
| 首次填表成功；随后累计跨过间隔 | 首次保存一份，此后达到间隔时每项完整成功任务最多保存一份 |
| 重复处理同层、手工标记进度 | 不重复累计，不凭手工标记产生自动版本 |
| 任务失败或取消 | 不生成该任务的自动版本，既有部分提交行为保持不变 |
| 刷新或切换聊天后返回 | 该聊天的历史及自动保存累计仍然存在 |
| 自动版本超过上限 | 删除最旧的自动类版本，手动版本保留 |
| 恢复时上限为 1，目标属于自动版本 | 目标及恢复前版本在操作期间可用，完成后裁剪 |
| 恢复前备份失败 | 停止恢复，当前记忆未被目标替换 |
| 恢复保存或核验失败后重试 | 明确展示未完成状态，不重复创建版本或空间副本 |
| 选错版本后再次恢复 | 可从保留的恢复前版本恢复原状态 |
| 导出三种来源的历史版本 | 文件均可由现有导入入口读取，内容与所选快照一致 |
| 三种来源的版本压缩保存后恢复或导出 | 解压后的完整快照与保存时一致，导出的 JSON 兼容现有导入入口 |
| 删除中间版本、仅浏览历史列表 | 其他版本仍可独立恢复，列表不需解压全部历史 |
| 压缩失败、压缩载荷损坏或格式不支持 | 遵循保存失败规则或拒绝恢复与导出，保留原数据并显示具体错误 |
| 恢复、导入或重建当前空间 | 当前聊天原有历史列表保留，自动累计按新状态重新建立 |
| 关闭自动保存 | 停止填表自动版本，手动保存、恢复前保存和已有版本仍可用 |
| 本机配额不足、版本损坏或聊天切换 | 显示明确错误，不误报成功、不覆盖其他聊天 |
