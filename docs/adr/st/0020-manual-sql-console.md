# 手动 SQL 控制台

日期：2026-10-24。

“检索”页增加“向量 / SQL”子 Tab。SQL 页直接执行当前记忆空间浏览连接上的 SQL，
允许 DDL、DML、PRAGMA、事务和多语句，不设置执行时长或返回行数上限。
语句边界由 SQLite 编译器识别；多个结果集分别展示，保留重复列名和空结果的列信息。

此能力独立于 Agent 的 `query_sql`。ADR 0019 中 Agent 的只读授权、预算和行数限制继续适用。
SQL 控制台不调用 authorizer、不调用业务写入服务、不建立隐式事务、不发布或保存记忆快照。
前面的语句已生效时，后续语句失败不会自动撤销它们；用户可显式使用 BEGIN / COMMIT / ROLLBACK。

控制台操作运行库，额外结构和修改不保证持久化。普通业务提交会替换浏览连接，切换空间或
刷新页面也可能重新加载数据库；SQL 修改可能随之消失。动态业务表是记忆实体的 SQL 投影，
直接修改投影不会同步修改实体 JSON、修订或证据。允许用户自行操作内部表，不做一致性修复。

SQL 草稿与结果仅保留在当前页面，切子 Tab 保留，切对话清空。执行后刷新结构与界面数据，
使向量检索和自动召回结果失效。语法或执行错误直接展示 SQLite 错误，保留输入供修改。
