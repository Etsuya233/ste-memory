# 跨插件共用已提交 SQLite 查询与临时视图

日期：2026-10-30。状态：已实现。

## 决策

在 `STE_MEMORY_API` v1 保留 `getContext`、`subscribe`、`read` 的基础上增加可选 `database` v1 能力，提供结构描述、临时 SELECT 视图注册和安全只读查询。适配器定义自己的业务表名和视图映射，Memory 仅管理通用注册、结构身份、查询授权与执行预算，不包含 Phone 等消费方的业务 schema。

查询直接使用空间既有的 committed SQLite 实例。描述只读取空间、表与字段，不复制全部记录；每条查询不额外建立求值快照数据库。普通记录提交不改变结构身份，消费方下一次查询即可看到新 committed 数据，允许跨查询弱一致性。未提交写连接保持隔离；当前普通和语义宏的独立求值会话不受本决策影响。

临时视图按空间与 namespace 管理，在 publish 替换 committed 实例时重新建立。表/字段结构或映射所需的标签、顺序、引用、显示策略和空间名称变化后，旧注册标为失效；消费方 describe/register 恢复，失效映射不会阻止正常 Memory 提交。结构身份排除记录内容和更新时间，另用加载生命周期身份区分同结构空间的卸载、重新导入和重载。

消费方只获得受限的 SELECT 视图定义能力，无法提交任意 host SQL。原生 SQLite 编译与 authorizer 同时验证视图体、视图展开后的真实底表和列；公开范围限启用的业务表/字段、系统记录列及所属 namespace 的视图。注册原子替换，禁止与现有业务表、内部表、保留名和其他 namespace 冲突。只读查询限制单条语句、命名标量参数、执行时间、行数与结果大小。

聊天身份与空间身份在异步操作前后检查。空间卸载或删除清理注册；视图不进入聊天镜像、备份、IndexedDB 快照或领域记录。接口细节见[公共只读接口](../../public-read-api.md)。

## 关系与验证

本决策扩展 [ST ADR 0019](./0019-sqlite-runtime.md) 的 committed 读取用途，保留其写入、发布和持久化边界；不修改 Agent SQL、手动 SQL 控制台或语义 SQL 权限。真实 WASM 测试覆盖提交可见性、发布后视图重建、结构失效恢复、名称冲突、展开授权、参数与执行预算；公共 API 与 runtime 测试覆盖聊天绑定、发布通知及记录提交后重新查询。
