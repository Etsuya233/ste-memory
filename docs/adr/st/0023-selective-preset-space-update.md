# 按 Key 选择性更新已有空间

日期：2026-10-26。状态：已实现，真实 ST 验收待完成。

## 决策

新增「从预设更新空间」，扩展 ADR 0017 的预设边界；预设编辑仍不自动传播，现有「应用预设」继续清空重建。新入口按表 Key、字段 Key 和向量分组 Key 展示树形差异，由用户勾选属性更新、完整对象新增和删除，保留匹配对象的身份及未删除的记忆数据。

向量分组新增可见 Key，名称独立编辑。预设保存 Key，创建空间和克隆保留 Key 并生成新 ID；向量仍用空间、表、记录、分组 ID 关联。旧空间缺 Key 时用原 ID 补齐，不推断与历史预设的对应关系。预设文件升级至 v2，旧用户设置预设缺 Key 时仅补本预设内序号 Key。

最终快照先检查显示、向量和引用依赖，再由 SQLite importSpace 在独立数据库事务内构建、成功后发布，构建或发布失败保留原空间。此路径保留记录身份、修订身份、台账、任务历史与初始化来源，不走会清理向量的备份恢复。删除字段明确移除当前与历史对应值及独占证据；已有字段类型不变，新必填字段不满足现有记录时由事务校验拒绝。

文件保存、缓存、宏刷新和向量核对分阶段报告失败。重试读取最新已提交快照，不重放选择或删除。通过 ChatSpaceManager.refreshSpace 刷新元数据，避免重新导入旧文件。预览绑定空间、对话身份和目标预设快照，提交前检查基线和当前身份。

## 验证边界

单空间操作；当前对话的可检查召回绑定会阻止分组删除，其他对话和 Prompt 自然语言依赖由原配置错误机制展示。没有类型转换、模糊匹配、自动预设跟随、批量迁移或跨存储整体事务。
