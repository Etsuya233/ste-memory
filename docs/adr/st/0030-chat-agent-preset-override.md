# 对话级 Agent 预设覆盖

Agent 提示词预设此前只有一个全局活动项，切换会同时影响所有对话。任务页需要在不改变全局默认的前提下，为当前对话固定一份预设。

对话级覆盖存于 chatMetadata 的独立键 `steMemoryAgentPreset`，载荷为 `{ version: 1, presetId }`。未写入或写入不存在的预设时跟随全局活动预设；`presetId = systemDefault` 是有效的显式覆盖，表示该对话使用内置系统提示词。预设覆盖与其他对话级选择一样随对话文件走，切换对话不会串用。

任务开始执行时解析一次有效预设，沿用既有“启动时冻结提示词配置”的语义：对话覆盖有效则优先使用，否则使用全局活动预设。覆盖指向的预设被删除后保留原 id，解析回退全局，任务页提示失效并提供清除入口；不扫描其他对话文件自动清理。

任务页提供“跟随全局 / 系统默认 / 命名预设”选择，写入前校验当前对话身份。全局活动预设仍由设置页维护，对话覆盖不改变全局设置。
