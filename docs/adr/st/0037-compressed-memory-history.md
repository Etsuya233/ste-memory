# 本机压缩记忆历史版本

日期：2026-11-11。状态：已实现。

## 决策

活动记忆空间继续由 SQLite 管理在线事务，由 ST 聊天文件保存完整快照。扩展 [ADR 0033](./0033-chat-file-only-memory.md) 的 IndexedDB 存储范围，按 ST 聊天文件身份保存本机历史副本。历史集合不参与空间加载、启动恢复、同步或旧空间辅助数据清理。

历史版本采用完整备份快照，将 UTF-8 JSON gzip 压缩为二进制。IndexedDB 分表保存摘要和载荷，摘要包含存储格式、压缩算法、字节数、楼层进度区间及记录数量。列表只读取摘要，恢复和导出只解压所选版本并进入共享快照迁移与验证。文件导出仍为单空间 JSON 备份。

SQLite 在线仓库保留已完成受管提交的快照，供历史保存、普通导出、强制同步与空间重建读取。填表结束使用最终保存批次交接的固定输入。SQL 控制台直接修改的查询连接、草稿与未提交事务不进入历史。自动保存累计由完整成功任务的新增处理楼层推进，部分失败和取消任务不推进。首次成功填表保存一份，其后按不同楼层累计，累计保存在 IndexedDB。替换或重建后的累计以新空间进度为基准。

## 恢复与保留

恢复确认绑定聊天、候选版本和当前受管快照。现有空间替换流程先停止旧工作并等待事务释放，再保存恢复前版本。旧快照有变化时重新预览和确认。文件保存与回读核验沿用原候选、重试和辅助数据清理流程，重试不会再次保存恢复前版本或克隆空间。

填表自动版本与恢复前版本共用每聊天保留上限，手动版本由用户删除。恢复期间保护目标和恢复前版本，核验后的裁剪按时间淘汰最旧自动类版本。历史只保存在当前浏览器，导出单份备份可手动转移。同一聊天的恢复保护在当前标签页运行，首版不协调多个标签页对同一聊天的并发历史操作。

完整验收场景见 [需求](../../checkpoints-requirements.md)。
