# 同步楼层作为来源身份（v1 接受漂移）

消息引用身份 = **同步楼层**（ST 消息数组下标），来源 ID 语义为同步顺序；删除、重生成、swipe 造成的下标漂移在 v1 接受，不传播、不回改。消息全文不落库——ST 本身是消息源，证据对比降级为点击楼层号跳转到 ST 对应消息。

选择楼层而非稳定身份的原因：ST release 的消息没有稳定 ID（身份即数组下标，无 hash/id 字段），稳定身份需插件自建哈希映射并为 swipe/regenerate 逐个定义语义，复杂度高；证据是快照（ADR 0011），早期消息变更导致的引用偏差可容忍；楼层跳转天然复用 ST 的原文展示，无需复制消息。

与领域词汇的关系：core 词汇表「证据身份不等同于外部聊天系统的楼层号」指领域概念——领域层不把楼层当证据身份；同步楼层是适配器层（st-extension context）的来源身份，两者不冲突。

不选方案：稳定哈希身份映射（swipe/regenerate/编辑语义复杂，留作后续加固）；全量重放对账（填表状态与证据引用全部作废）；随消息同步存全文副本（数据膨胀，ST 已是消息源）。
