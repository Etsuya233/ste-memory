# ADR 0021 — 标签清洗 v2

## Status

Accepted（2026-10-25，用户确认仅保留标签模式，丢弃旧配置）

## Context

原有清洗规则支持标签/正则和保留/去掉/替换组合，并支持 ST 正则导入，配置和维护复杂度过高。
本决策取代 ADR 0011 和 ADR 0014 中的规则模型、导入及旧配置兼容约定。

## Decision

- 每条规则只有名称、启用状态、保留标签对数组、排除标签对数组。至少填写一对完整标签。
- 同组为 OR，按原文顺序匹配，重复配置不重复输出；不同标签嵌套时取最外层完整匹配。
- 先保留后排除。保留剥掉边界，多个非空片段用换行连接；未配置保留使用全文，配置但未命中输出空文本。
- 排除删除整段，保留和排除配置同一标签时排除优先。
- 标签按字面区分大小写，支持跨行；保存时 trim 标签。缺少结束标签不构成匹配。
- 保持简单配对，不解析 HTML/XML 属性，不支持同名嵌套。起止标签可相同。
- 删除正则执行、替换、ST Regex 导入及宿主读取端口。保留列表 CRUD、排序、对话选择和草稿清洗测试。
- 独立 `cleaningSchemaVersion: 2` 控制全局清洗配置，旧版或没有版本号时清空列表并保存新版本，不迁移旧规则。
- 对话选择使用 `{ version: 2, listId }`，打开对话读取选择时删除旧指针并保存，其他 metadata 不变。
- 清洗范围继续为填表输入（含初始化文本），消息和证据不改写；任务沿用开始时的规则快照。

## Consequences

升级后需要重新创建并选择清洗列表；不保留旧规则执行路径。其他插件设置和记忆空间不变。

## Validation

- 全量 Vitest：135 个文件、1471 项测试通过，覆盖标签顺序与 OR、排除优先、未命中、字面匹配、配置版本重置和启动/切对话清理。
- TypeScript、ESLint、Prettier 与生产构建通过。
- Browser Use 在独立组件预览中验证列表创建/选择、空规则校验、标签增删、草稿测试、保存后测试与 390px 窄屏无横向溢出。
- 浏览器验证使用独立预览；填表输入与证据保持原文的行为由集成测试验证，未修改已安装 ST 实例。
