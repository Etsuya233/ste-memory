# 完整查询表达式、对话宏与生成时统一求值

拟将命名宏定义为一份完整 Query 或 SQL 表达式，向量提供相关度，表达式决定最终字段、条件、排序和条数。放弃“候选 SQL＋外部 Top K／投影”的初稿，避免用户无法从 SQL 判断最终输出。Query 增加 semantic 与相关度字段；SQL 首版采用同一表达式中声明的命名评分源，无内置 Top K，不承诺尚不存在的表值函数。

局部宏统一称为对话宏，表示当前对话绑定记忆空间中的宏，与预设结构共同提交和传输，不另设空间宏层。同名优先级为对话、全局、内置。共享空间共享定义，执行仍使用各自对话上下文；旧对话同名不同定义无法自动保持独立覆盖，迁移保留原数据并明确处理冲突，不另造永久局部层。

根据用户明确要求，取消后台预计算，每次实际生成统一执行启用宏。固定本批记录及配置输入，同批查询向量共享，跨生成重新计算；ST 同步回调只读取本次结果，群聊批次及同次递归复用。记录编辑留给下一批，切对话、停止与替代操作取消结果归属。语义源可以由宿主异步评分后物化进隔离 SQLite 求值会话，用户 SQL 仍只读，不在同步 SQL 回调或 ST 宏回调里等待网络。

本提案调整 [宏注入 ADR 0004](./0004-macro-injection.md) 的计算时机，扩展 [记忆视图 ADR 0025](../0025-memory-views-and-memory-query.md) 的定义与求值方式，并补充 [表格预设 ADR 0017](./0017-table-presets.md) 的复制内容；保留用户手动放置宏、同步展开和只读边界。宏统一一个启用开关，预设复制的语义宏默认关闭；无有效索引产生空评分关系，SQL JOIN 类型决定其输出，执行错误则所属宏为空、原因可见，其他宏及主生成继续，不用旧值或同名来源兜底。

按用户明确要求整块废弃 memoryRecall，删除专用宏、自动召回配置、独立开关、视图绑定和旧服务，不提供兼容入口、别名或自动转换器。新表达式的语义源承担召回，手动检索及索引保留，旧提示词引用由用户自行替换。新宏体系只使用宏自身的启用状态。

需求与验收见 [宏重构需求](../../../.scratch/macro-expression-refactor/spec.md)，双方取舍见 [质询记录](../../../.scratch/macro-expression-refactor/discussion.md)。该 ADR 记录拟议方向，尚未替代已实施行为。
