# 聊天文件作为空间内容唯一持久化来源

日期：2026-11-01。状态：已实现。

## 决策

空间、表、字段、记录、历史与证据统一由 SQLite 在线管理，对话文件保存完整快照。
IndexedDB 只管理独立的任务、楼层台账、向量、助手会话和日志；v12 直接废弃六类旧空间表。
旧本地空间不扫描、不校验、不迁移、不导出、不用于存在检测。旧文件 v1/v2 仍走统一快照迁移。

`SqliteMemoryStore` 管 SQL 事务归属与已提交事件；保存与编辑门控为必需构造端口。
提交并导出后，同步把独立快照交给 `ChatSnapshotPersistence`，SQL writer 随即释放。
宏、向量和公共只读接口通过已提交事件失效，异步刷新失败不能改变提交结果或阻断文件保存。

`ChatSnapshotPersistence` 按文件目标持有最新有效快照、绑定及任务阶段。
普通更新是 write → complete，complete 确认已保存填表批次；候选替换是 write → activate。
文件已成功时，重试只继续确认或激活；同目标旧结果不发布到新 metadata。
离开已保存聊天释放完整内存快照，未完成任务保留；返回未保存聊天优先恢复待保存输入。

每个聊天只激活当前空间。导入或分支副本在纯快照函数中重映射 ID，经 SQLite 独立验证，
再同次保存 binding 与 snapshot；成功前不发布新绑定、不清原辅助数据。候选保存期间停止旧写入，
异步校验归属在排队前集中核对。保存成功后才清旧辅助并激活，分支副本不删除源聊天数据。
退休/卸载持有原文件目标，防止迟到保存误清相同空间 ID 的其他活动文件。

卸载仅释放 SQLite。向量只执行当前空间队列，离开只中断 running 并保留 queued。
真正的替换、清除和预设重建由对应业务顺序调用辅助模块清理，不用空间删除钩子模拟生命周期。
本地空间目录、全库备份/恢复、同步开关、Dexie 空间仓库及轮询式镜像架构全部移除。

## 版本与边界

保留 [ADR 0032](./0032-unified-memory-snapshot-migration.md) 的文件领域迁移、当前校验及版本边界，
取代其本地缓存迁移条款；取代 [ADR 0019](./0019-sqlite-runtime.md) 的 IndexedDB 双写缓存。
备份文件外壳读取兼容历史集合，但当前聊天导入只接受一个空间，当前导出不携辅助数据。

不引入 identityKey、跨聊天空间目录、多存储后端或服务端协议变更。
正常字段删除的孤立证据业务不在本次范围。SQLite 提交、文件写入与辅助台账没有共同事务，
保存失败由明确内存待办表示；关闭页面仍可能失去未完成内容，不建立跨刷新确认协议。
