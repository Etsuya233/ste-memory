# R2 云同步：文件格式与同步模型（ticket 08）

插件（st-extension）把 Dexie 记忆数据同步到 Cloudflare R2，作为双端
（云酒馆浏览器 / TauriTavern iOS）的唯一通用持久层（iOS WKWebView 本地存储
可能被系统驱逐，云同步是必需而非加分项）。同步模型：**本地优先 + 变更防抖周期
推送 + 空库启动拉全量 + last-write-wins**。

## 格式（core `src/memory/cloud/`，与备份文件同信封）

- 信封与备份文件完全一致：`{ format: "ste-memory-backup", version: 1, exportedAt, appVersion, ... }`
  ——format/version 语义相同，未知版本解码时明确报错（`memory_cloud_version_unsupported`），
  **绝不覆盖本地**；结构与完整性校验直接复用备份 codec（`memorySpaceBackupSchema` +
  `validateSpaceBackupUnit`，错误文案按「云同步文件」措辞）。
- **空间文件** `spaces/<spaceId>.json`：信封 + `spaceId` + `updatedAt`（该空间最近
  一次变更时间 = LWW 键）+ `data`（单个记忆空间序列化单元，与备份文件
  `data.spaces` 元素同构）。
- **索引文件** `index.json`：信封 + `spaces` 清单（`spaceId` + `updatedAt`）——
  空库拉取的目录、推送时 LWW 比较的依据（版本号 = 信封 format version；
  更新时间 = 条目 updatedAt；「版本号 + 更新时间」共同构成索引内容）。
- 编解码是 core 纯函数（未来 api 服务端云同步可复用同一份格式），I/O 走
  `CloudSyncAdapter` 端口（`getObject` / `putObject`，404 读返回 null 不是错误）。

## 同步模型（插件纯逻辑 `src/cloud/sync-coordinator.ts`）

- **变更检测**：轮询 Dexie 空间指纹（五张子表行数 + 全空间最大 updatedAt——
  core 服务只更新变更实体自身的 updatedAt，空间行不随记录变更刷新，指纹是
  可靠且便宜的等价判定）；与上次推送指纹比对出脏空间。
- **推送**：脏空间经 3s 防抖窗口合并 → 先逐个写空间文件（与云端索引 LWW 比较：
  云端较新或相同 → 跳过不覆盖），再整体写索引文件；索引写失败不标记已推送，
  下轮重传（幂等覆盖）。启动即推送全部脏空间（指纹为空，靠 LWW 跳过无变化者）。
- **拉取**：仅本地库为空时（`start()` 先于空间创建执行 + 落地前二次确认仍为空，
  避免覆盖启动期间新建的空间）；索引 → 逐空间文件校验（索引条目与文件身份
  不一致时跳过该文件）→ `restoreSnapshot` 原子整体恢复，任一文件失败即中止，
  绝不半拉取；完成后回调宿主重同步当前对话绑定。启动与「立即同步」都会评估
  拉取（本地仍空时手动同步可取回另一设备后来上传的数据），日常轮询不重复拉取。
- **失败重试**：错误状态 + 指数退避（10s 起，封顶 5min），轮询周期内自动重试；
  「立即同步」（syncNow）忽略退避强制跑一轮。
- **开关**：R2 四项配置齐全 && 插件总开关开启即生效（设置实时修改立即生效，
  凭证每次请求重取）；未配置时零网络活动。

## 为什么这么设计

- **放 core 的**：信封格式与编解码（与备份共用同一份定义，双份实现必然漂移）、
  LWW 冲突裁决、`CloudSyncAdapter` 端口。**放插件的**：SigV4 签名（R2 S3 兼容，
  浏览器无 AWS SDK 可用）、R2 适配器（fetch + 错误映射）、协调器（防抖/拉取/
  重试）、Dexie 指纹实现。
- **本地优先**：离线可用（spec 决策 6）；拉取只服务「新设备 / 存储被清」恢复。
- **LWW 用 updatedAt 而非自增版本号**：离线多端各自递增的版本号无法全局有序，
  时间戳是唯一诚实的全局比较键；同毫秒并发编辑视为相同（不覆盖），v1 接受
  （spec「多设备并发冲突解决（LWW 足够）」）。
- **索引先读后写有并发竞态**（双端同时推送时后写覆盖先写）：空间文件本身按
  LWW 逐文件比较仍安全；索引竞态仅影响「另一端的空间暂时不出现在目录」，
  v1 接受并记录，后续可在索引条目上做 compare-and-write。

## 边界与代价

- 本地删除的空间不传播删除（云端文件保留，另一端拉取后复活）——v1 记录为
  限制，删除传播留后续版本。
- 密钥明文存浏览器设置（ADR 0017 精神）；`appVersion` 仅诊断信息。
- 拉取仅在启动/立即同步时评估；会话中途本地被清空不会自动重拉（重启即恢复）。
