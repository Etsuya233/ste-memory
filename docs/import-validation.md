流程覆盖单聊导入、同文件重复导入、独立 ID 与稳定身份、非法 JSON 不改内容、错误到关联日志跳转、刷新后重新打开聊天、群聊导入、核验 HTTP 503 后沿用同一空间重试、旧 Agent 会话清理失败后单独重试、群聊刷新、损坏聊天文件恢复，以及窄屏横向溢出。

每次成功导入、重试和重载均比较原生聊天文件中的完整 Memory 快照与 SQLite 导出。核验失败通过路由制造 HTTP 503；清理失败通过一次性替换清理方法制造，重试执行原清理。其余保存和回读均经过真实 ST 接口。

以上结果覆盖本机 ST 与 Edge；原手机现场的具体不一致原因仍缺原始差异记录。

## 复跑入口

使用专门的 ST 测试数据目录启动实例，确保该实例中仅启用待测插件，并将当前构建安装或链接到扩展目录。脚本会创建测试聊天和群聊、制造损坏快照以验证恢复。

```powershell
$env:ST_URL = 'http://127.0.0.1:18842'
$env:ST_IMPORT_TEST_INSTANCE = '1'
$env:CHROME = '<Edge 或 Chromium 可执行文件>'
node --experimental-strip-types docs/playwright-st-extension/verify-import-roundtrip.mjs
```

脚本使用 Playwright Core。设置 `IMPORT_BACKUP` 可读取指定备份；`ST_TEST_WIDTH=320` 验证窄屏；`IMPORT_RESULTS` 指定 JSON 结果文件。默认使用合成备份，不在输出中打印记忆正文。
