# 记忆视图与世界书注入（用户文档）

记忆宏 = 一个全局前缀（默认 `{{ste}}`，可在设置面板改名）+ `::` + 名字的**统一分发**：
`{{前缀}}` 无参展开全部启用表分组快照；`{{前缀::名字}}` 按名字分发——同名优先级
对话级宏 > 全局视图 > 内置宏（`full` / 表 Key）。**记忆视图**是插件级命名选取配置：
{表格、筛选条件、条数上限、显示字段}。设计决策：`docs/adr/0025-memory-views-and-memory-query.md`。

## 语法

| 写法 | 行为 |
|---|---|
| `{{ste}}` | 无参 = 全部启用表分组快照（分组标题 + 显示文本 + 上限截断） |
| `{{ste::full}}` | 内置宏：全部启用表完整数据（Markdown 表格，每表一个 section） |
| `{{ste::角色}}` | 内置宏：单表完整数据（表 Key 是字符串参数，中文表 Key 可直接用） |
| `{{ste::未完成伏笔}}` | 展开名为「未完成伏笔」的全局视图快照 |
| `{{ste::坏宏}}` | 当前对话有同名对话级宏 → 对话级宏优先（同名覆盖，局部优先） |
| `{{ste::不存在的名字}}` | 空串（不阻断生成，插件日志提示） |
| `{{ste::a::b}}` | ST 参数校验失败（宏只接受 0/1 个参数） |
| `{{ste::}}` | 空参数：ST 解析层不产生参数（宏保持字面量回退原文）；handler 对空名字参数同样展开空串 |

名字约束（ST 宏参数语法）：不含空白、`::`、`|`、`}}`；中文可用；视图名全局唯一、
对话级宏名当前对话内唯一。设置面板与设置合并层双重校验，非法名字不会入库。

## 配置视图（设置面板 → 记忆宏组）

- **视图名**：如「未完成伏笔」「最后 5 条剧情」。
- **表格**：选择活动空间的表（视图按活动空间求值；其他空间没有该表时展开为空串，
  面板会显示配置错误）。
- **筛选字段/筛选值**（可选）：v1 只支持 single_select 与 short_text 字段。
  single_select 字段 = 选项多选（匹配任一值）；short_text = 手输多个值（逗号分隔）。
  语义是 `in`（值集合成员匹配）——「排除已回收/已放弃」即勾选其余状态。
- **条数上限**（可选）：最多返回 N 条（按 `$updated_at` 倒序，最新在前）。
  留空 = 最多 100 条（core 查询契约上限）。
- **显示字段**（可选）：勾选后每条记录按「字段名：值」渲染；引用字段显示目标记录
  的显示文本。不勾选 = 沿用记录显示文本。

视图变更（新建/编辑/删除）立即生效（设置写入即触发快照重建），无需重启。

## 求值语义 = 记忆查询契约

视图的选取翻译成 core **记忆查询**（查询 Agent 工具与 apps HTTP 查询共用同一契约
与实现）：`in` 筛选 + `$updated_at` 倒序 + 分页。因此视图输出与查询 Agent 同语义，
行为可预期。翻译失败（表/字段不存在，含字段 Key 被改名；表/字段被停用）→ 展开
空串 + 日志，设置面板对应视图行显示「配置错误」。

## 世界书（World Info）用法

宏放在 **WI 条目内容**里即可，插件零改动（ST 1.18.0 在条目激活时无条件展开自定义宏）：

1. 在 ST 世界书里新建条目，关键词设为触发词（如「伏笔」），内容写
   `{{ste::未完成伏笔}}`（或直接写 `{{ste}}` 用默认快照）。
2. 生成时剧情文本命中关键词 → 条目激活 → 宏展开为对应视图快照，注入上下文。

要点：

- **constant 条目** = 常驻注入变体：把宏放进 constant 条目，不依赖关键词，每次都注入。
- **预算**：世界书预算按**展开后**内容计 token——视图输出越大越挤占 WI 预算。
  用视图的条数上限 + 设置面板的记忆宏字符上限控制体积。
- **关键词也会做宏替换**：触发词里可以嵌其他宏（不影响本功能）。
- `experimental_macro_engine`（ST 设置里的新宏引擎开关）关闭后自定义宏不展开——
  既有风险，本功能不处理。
- 视图按**活动空间**求值：跨对话切换空间后，视图展开的是新空间的同名表数据；
  新空间缺表则展开为空串。

## 限制

- 筛选 v1 = 单条件（一个字段的 in 值集合）；多条件 AND、更多算子（contains/gt/lt 等）
  契约已支持，仅差面板 UI 暴露。
- 视图无独立字符上限字段：输出受全局「记忆宏字符上限」兜底（尾部截断 + 标记）。
- 视图是插件设置，全局生效（不随对话文件走）。
- 对话级宏随对话文件（.jsonl）导入导出，且在对应对话内优先于同名全局视图与内置宏。
