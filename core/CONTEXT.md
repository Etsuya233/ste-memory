# SillyTavern Memory

该上下文描述一个辅助 SillyTavern 长对话记忆的系统。它在有限上下文窗口之外维护可修订的当前认知，但不取代原始对话。

## Language

**对话记录**：
会话中按顺序产生的原始消息，是记忆结论的最终证据来源。
_Avoid_: 记忆

**清洗规则**：
按顺序执行的正则规则，以「保留」「去掉」或「替换」模式改写消息内容；规则只在读取时应用，存储的原始消息内容永不改写。规则的组织与生效范围由各客户端决定：apps 为每记忆空间一份、影响展示与填表任务输入；ST 插件为插件级规则列表、由每个对话选择、只影响填表任务输入。
_Avoid_: 正则脚本、过滤规则、文本替换

**证据条目**：
从数据源中识别并保存身份的一段原始内容，可被记忆字段值引用以说明其来源。适配器决定它保存完整快照，还是只保存外部定位信息；证据身份不等同于外部聊天系统的楼层号。
_Avoid_: Agent 原因、记忆记录

**记忆表格**：
从对话证据中整理出的、可由模型或用户修订的当前认知集合，用于增强模型对长对话的记忆。它不是原始对话，也不天然等同于客观事实。
_Avoid_: 聊天记录、事实库

**记忆记录**：
记忆表格中的一条当前认知，可以保留其来源证据与修订历史。
_Avoid_: 原始事实

**表格填写 Agent**：
依据对话证据、表格定义和填写意图提出记忆记录变更的执行者。它提交的结果仍需遵守与用户手动修改相同的领域规则。
_Avoid_: 领域模型、数据库写入器

**查询 Agent**：
依据记忆空间内容回答用户提问的只读问答执行者。它只通过只读查询获取记录并如实回答，不提出记忆记录变更。
_Avoid_: 聊天机器人、问答助手

**表格定义**：
描述一个记忆空间中某种记忆表格的字段和填写意图。系统表和自定义表共享同一种表格定义，且定义的修改不会传播到其他记忆空间。
_Avoid_: 专用表模型

**定义 Key**：
用户可读的表格或字段标识。表格 Key 在记忆空间内唯一，字段 Key 在所属表格内唯一；它与数据库身份分离，可以在创建后修改。
_Avoid_: 数据库主键、显示名称

**系统表**：
由 API 或三方模块提供完整默认定义的记忆表格，例如人物、地点或剧情表。系统表通过通用表格服务安装，Core 仅区分其 kind；创建后可在各自记忆空间中修改。
_Avoid_: 专用实体表

**自定义表**：
由用户定义用途、字段和填写意图的记忆表格，与系统表遵循相同的领域规则。
_Avoid_: 动态表

**引用字段**：
保存同一记忆空间内其他记忆记录身份的字段，可以包含单个或多个引用。引用保存目标身份，而不是复制目标记录的显示文本；仍被当前记录引用的目标不能单独删除。
_Avoid_: 文本关联、跨会话引用

**显示策略**：
一个表格向用户和 Agent 表示记忆记录的方式，可以是短文本显示字段，也可以是由其他字段派生的显示模板。显示值允许重复，不承担记录身份职责。
_Avoid_: 主键、唯一名称

**统一表达式**：
结构化描述记忆记录选取的 JSON 数据：条件数组（字段 Key + 算子 + 值集合，多条件 AND 语义）、排序、条数上限；由 core 纯函数求值（筛选→排序→取条数，返回记录子集）。v1 算子为 in（枚举多值）与 eq（短文本精确），排序固定 updatedAt 倒序。各客户端负责把用户输入翻译成统一表达式，apps 与 st-extension 共享同一结构与求值。
_Avoid_: 查询语法、筛选字符串、表达式 DSL

**字段证据**：
一个具体字段值对零到多个证据条目的引用。用户手动填写的字段值可以没有字段证据。
_Avoid_: 行级来源、Agent 解释

**记忆空间**：
一段独立会话所拥有的记忆边界，其中的表格、配置、记录和历史不与其他会话混用。外部聊天系统的会话标识不属于记忆空间的领域身份。
_Avoid_: SillyTavern Chat、数据库表

**备份文件**：
一个记忆空间库的完整序列化单元集合（每个记忆空间一个单元，含表格定义、记录、修订历史与证据），带格式与版本信封，供导出/导入与云同步（ticket 07/08）共用。编解码是 core 的纯函数，存储 I/O 由各平台经备份存储端口实现。
_Avoid_: 数据库导出、存档

**云同步文件**：
云同步在云端为每个记忆空间保存一个序列化单元文件（空间文件，与备份文件共用 format/version 信封，外加 spaceId 与更新时间），并维护一个含空间清单的索引文件（同步索引）。两者与备份文件共享同一信封语义：未知版本解码时明确报错，绝不覆盖本地；冲突按 last-write-wins（较新更新时间胜出）裁决。
_Avoid_: 数据库备份、上传对象

**修订批次**：
一次不可分割的记忆记录数据变更集合，直接通过相关数据行共享的修订身份表示，不拥有独立的批次头。表格定义、Prompt 和开关不属于修订批次的版本范围。
_Avoid_: 全量快照、原地回滚

**历史记录**：
正式表中一条记忆记录在被替换或删除前的旧状态。历史记录拥有独立身份，同时保留原记忆记录身份及导致其归档的修订身份。
_Avoid_: 当前记录、完整变更日志
